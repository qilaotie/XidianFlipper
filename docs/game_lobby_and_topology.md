# 游戏邀请、准备、观战与网络拓扑演示

2026-10-30。本轮基于[多桌大厅](multi_table.md)，每台设备仍同时参加或观战一桌。请统一更新所有参与设备；旧固件没有准备操作，不能完成新版桌主的全员准备开局条件。

## 游戏邀请

入口：趣玩 → 多人桌游。桌主创建一桌后，在该桌等待大厅选择“邀请本队伍玩家”。同频道、同队伍的在线设备可在多人桌游底部“游戏邀请（数量）”中看到邀请。公共空间的邀请发给同频道公共空间，不会发到其他队伍。

接收者选邀请、看清桌主和游戏后，选择“加入或恢复我的座位”。不会自动加入，也不会抢走正在玩的桌。无法接收邀请的离线设备不补发；附近游戏桌仍可正常发现并加入。

每桌主最多每五秒成功排队一次邀请。邀请列表标记保留约六十秒，桌已开始或发现状态过期后不再列为待加入邀请。重复广播不延长同一邀请的有效期。“邀请已排队”仅表示提交到发送队列，不代表所有设备均已收到。列表在打开或刷新时固定，避免条目换位；未看到新邀请时点击刷新。

## 准备状态

- 桌主建桌时默认准备，可以切换为未准备；其他玩家加入后默认未准备。
- 每位玩家在自己的桌大厅选择“我的准备”，短按切换。等待回执和状态同步后再进行下一步。
- 大厅显示“已准备 X/N”，玩家名单逐人显示已准备/未准备。
- 人数满足游戏下限，且每位玩家都准备好后，桌主才可开始。不会自动开局。
- 新玩家加入会清除原有非桌主玩家的准备状态，大家要重新准备；迟到的旧人数准备请求不会重新生效。
- 准备操作支持回执重试与去重；准备状态保存在内存，不写宠物、好友、草稿等存档。

## 观战

附近游戏桌或邀请的详情页中选择“观战公开桌面”。等待公开状态同步后，可查看棋盘、明牌、公开出牌、玩家状态和比分。UNO 观众显示各玩家手牌数量；骗子酒馆显示声明点数、上一手数量和生命；身份游戏只显示当时允许公开的信息，结束时可看公开结算。

观战不加入玩家名单，不占座位，不提交准备、出牌、技能、投票或结束对局操作。观众的“我的手牌/身份”和“执行操作”入口都只打开公开信息。长按也不会揭示其他人的手牌、身份、查验结果。观战采用软件层的公开信息过滤；原通信没有新增加密或身份认证。

返回桌大厅选择“退出观战”，只退出本机，不结束正在观看的游戏。观众可换桌；正在参加一场有效对局的玩家需先结束当前局，才能换桌或转为观众。原有玩家“确认结束整局游戏”的行为保持不变，不要把它当成观众退出。

## 网络拓扑演示

入口：工具 → 扫描与诊断 → 网络拓扑演示。

- **邻居图**：本机与最近收到直接邻居广播的设备连线，每屏最多两位邻居。旋转可浏览最多十六位；底部显示所选邻居 RSSI。邻居约十五秒无广播后不再显示。这里只画“本机收到过该邻居广播”的关系，不保证双向可达，不画邻居之间的假想连线。
- **消息观测**：短按切换到最近八条路由消息元数据；旋转选择记录。显示原始来源/目标地址尾码、消息类型、十六进制消息编号、接收时跳数 H、最后一跳 RSSI（LRSSI）和记录年龄。只记录公开元数据，不显示消息内容、手牌或私密身份。
- **统计**：再次短按显示本机转发 FWD、去重 DUP、丢弃 DROP 累计计数，重启后重置。
- **解释**：再次短按说明“仅绘制邻居广播、中继路径未知”；再短按回邻居图。
- **长按**进入原网络诊断列表，查看回执耗时、重试和超时等；**返回**退出当前页。自组网关闭时，短按打开网络设置，由用户主动开启。

跳数来自收到的包头，包含最后接收到的这一跳。转发保留原始来源地址，因此来源不一定是直接发射该包的设备；LRSSI 属于最后一次无线接收，不能当作原始来源的距离。普通路由包不会被画成直接邻居，只有符合直连广播格式的邻居报文进入邻居图。当前协议没有完整路径字段，不能据此还原 A→B→C，也不把 RSSI 换算成米。拓扑页展示的是当前频道的底层网络观测，不等同于队伍成员名单；可能看到该频道中其他队伍的设备广播和包头元数据。

## 验证范围

已通过 ESP-IDF 5.5.4 编译与宿主生产代码回归：邀请限频/过期/重复处理、全员准备门槛、准备取消与 ACK 去重、新人加入清准备及旧请求失效、只读观战/私密帧拒绝/退出不结束对局、多桌独立推进，以及真实渲染函数的邻居专属连线、消息与邻居分离、十六邻居/八事件边界、过期、计数和 128×32 坐标检查。原有十款规则 400 场完整模拟和八万次随机尝试、丢包重试、分片、中文、帮助及网络消息回归通过。

2026-10-30 已将配套固件更新到 COM9、COM10、COM15，并检查三台拓扑页面入口。邀请、全员准备、观战的完整实机对局未在本次发布中重新验收；宿主回归和以前版本的实机记录不能代替这部分验收。详见[发布验证](release_2026_10_30_validation.md)。
