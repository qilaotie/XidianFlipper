# 贪吃蛇

入口：`FUN > Snake`（单机游戏组），横屏游戏，左侧 24×8 格棋盘，右侧得分。

- 短按旋钮开始，再短按暂停/继续。
- 顺时针：沿当前前进方向右转 90 度。逆时针：左转 90 度，不是屏幕绝对左右平移。
- 每移动一格最多接受一次转向，避免快速转两格导致原地掉头。
- 长按重新开局并开始，BACK 随时退出。
- 撞墙或撞自己结束，短按重开。吃空心食物增长一格并加 1 分。
- 初始移动间隔 240 ms，每吃一个加快 10 ms，最快 90 ms。没有穿墙。
- 填满棋盘获胜。分数/进度仅在 RAM，重新进入是新局，不写入 NVS。

`tools/test_snake.c` 覆盖食物不占蛇身、增长、转向限制、撞墙/自身/移动尾巴、满盘获胜及 50,000 步不变量。

`python tools/test_snake_ui.py` 编译生产页面，用绘制/输入/时钟替身验证像素边界、暂停、重开及退出，是宿主测试，不是实机验收。

`python tools/smoke_snake.py --port COM9` 通过 USB 操作真实游戏入口、开始/转向/暂停/重开/退出与重入，保存截图到 `build/snake-smoke/`，不修改持久设置。不能代替真人长期游玩。
