48 表情版已烧 COM9：完整应用回读、分区表及两处 NVS 不变校验通过；实机遍历六分类全部 48 行并逐级返回，通过，无重启、无发送、无草稿修改，最终回首页。生产 UI 的全部表情插入与单独发送路径由主机测试覆盖；这次实机只检查列表，不把它描述为 48 次实际发消息。截图及私有日志保留在忽略的 `build/emote-smoke/`。

## 文档与源码怎么分享

- 快速功能介绍：`docs/给原开发者的功能简介.md`、`docs/功能简介.md`。
- 日常操作：`docs/使用手册.md`、`docs/宠物功能使用手册.md`、`docs/menu_navigation.md`。
- 完整源码：分享 GitHub 仓库或仓库源码压缩包最稳妥。至少保留 `firmware/`、`main/`、`components/`、`tools/`、`docs/`、根目录 `CMakeLists.txt`、`sdkconfig.defaults`、分区 CSV、`build.ps1`、命令入口和许可证文件；仅给某个 `.c` 文件不能独立编译。冻结发布资料可以一并保留，但不应冒充最新镜像。
- 不发送 `build/`、`.publish/`、`.git/`、本机 `sdkconfig`、串口日志、私有 Flash/NVS 备份、热点截图或凭证。SDK 工具链由接收方单独安装 5.5.4。
- 设备更新仍须遵守[分区迁移与数据保护](partition_migration.md)，不能整片擦除、单刷分区表或混用不同构建产物。
