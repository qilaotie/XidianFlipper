## 固件与分区

旧固件只支持连接 Wi-Fi，不会上传。同步版先按[分区迁移](partition_migration.md)备份并迁移到 2 MiB 主程序槽。已迁移设备可用 `tools/flash_update.py` 更新应用，该工具会核对真实分区、备份程序与 NVS、只写应用并回读校验；旧三槽设备会被拒绝。

ESP-IDF 5.5.4 / ESP32-C6。当前含命名/三地图的应用 1,527,808 字节，剩 556 KiB，指纹见[发布说明](最终版发布说明.md)。本文云端实机链路的先前云版本为 1,525,280 字节、SHA-256 `3af0827cdf2dca509644604d9f691c338c1572203a4103cbddf4d9060d30157e`，不把历史上传记录误写成当前完整联网回归。

## 设备操作

先在 `TOOLS > Wi-Fi connect` 连接可上网的 2.4 GHz 网络。自动重连沿用原设置，不会因打开云分享而被擅自开启；重启后没有自动连网时可选 Connect saved。

进入 `TOOLS > Cloud sync`，转动选择以下四项，独立 BACK 返回：

| 当前项 | 操作 | 作用 |
|---|---|---|
| HOLD: SHARE ON/OFF | 长按旋钮 | 开启/关闭分享。首次安装默认 OFF，短按会提示公开数据确认 |
| CLICK: SYNC NOW | 短按旋钮 | 分享已开时立即请求同步，或重试待移除任务 |
| HOLD: REMOVE ONLINE | 长按旋钮 | 关闭分享，撤下自己的云端宠物与云端分数，不动本地存档 |
| CLICK: WI-FI SETTINGS | 短按旋钮 | 进入网络设置 |

开启后联网每约 15 分钟同步，也可立即同步。首次可能需要先校准网络时间；`SYNC OK / AUTO 15M` 表示收到服务器成功确认。# 后的六位是随机公开身份前缀，不是 MAC 或密码。

**关闭分享只停止后续上传，不自动撤下已公开的数据。** 要撤下请用 REMOVE ONLINE；已经在途的请求可能在关闭时完成。移除意图会先保存，离线时等待连网再重试，重启保留；待移除期间不能重新开启分享。移除后重分享仍用原身份，读取保留的本地纪录重建云端成绩。

## 网站显示

- 贪吃蛇最高食物数，长度 = 食物数 + 初始三节。
- 俄罗斯方块最高分与累计消行纪录；两者分别保存，不一定来自同一局。
- 昵称、宠物年龄/阶段、形态、金币、四项养成状态和睡眠状态。
- 每个榜前 100 条，同分按云端达成时间、随机 ID 排序；展示柜为最近更新的 100 台。
- 数据是上次上传快照，不是实时在线状态，网页缓存可能延迟约 30 秒。

云端最高分只增不减；主动移除会清空自己的云端成绩，重新分享会从本地纪录重建。排行榜是设备自报交流展示，非严格防作弊比赛。不会从云端恢复本地完整棋局。

## 身份、隐私和错误处理

每台设备首次开启时生成 128 位随机身份和 256 位独立上传凭证，先存入 `cloud_user/state_v1` 再允许上传。不开源共享密钥、不用 MAC 作公开 ID，不把凭证放到 OLED 或日志。身份重启后保持不变；NVS 损坏/未知版本不自动覆盖，保存失败会阻止上传。

不上传 Wi-Fi 密码、SSID、邮箱、手机号、位置、好友、私信或完整棋盘；昵称请勿包含隐私。Flash/NVS 备份可能含密码和凭证，只留在忽略的 `build/migration-private/`，不能上传或发给其他人。

HTTPS 校验证书与主机名，未设置跳过校验或 HTTP 降级；无有效网络时间时等待，不绕过证书有效期。UI 所有者创建不可变快照，后台只做网络，不直接读取或更改宠物/游戏 UI 状态。读取纪录不加载棋局、不改奖励水位或发金币。

上传队列串行，失败按 60、120、240、480 秒退避；手动频繁同步可能收到 429，服务端同设备至少间隔 60 秒。关闭、重启、掉网和深睡可能打断请求，不保证本地标记与云端操作构成跨系统原子事务；服务器最高分合并和持久化移除意图减少重复/丢状态风险。

| 提示 | 排查 |
|---|---|
| SHARING OFF | 长按第一项开启；连上 Wi-Fi 不等于允许公开分享 |
| WAIT FOR WI-FI | 先连接热点并确认允许上网 |
| WAIT FOR NET TIME | 网络时间校准失败，稍后重试 |
| NETWORK ERROR / RETRY | DNS/TCP/TLS/HTTP 故障，不能仅凭这个断言密码错误 |
| RATE LIMIT / RETRY | 等待冷却，不要连续触发 |
| CREDENTIAL REJECTED | 保留 NVS 排查，不要随意换新身份 |
| CLOUD SAVE ERROR / LOCAL DATA ERROR | 先备份已有数据，排查存储/记录 |
| REMOVE: NEED WI-FI | 已保存移除意图，连网后重试；未完成前数据可能仍公开 |

## 部署与免费边界

网页仍在 GitHub Pages。设备/网页 API 为 `https://xidianflipper-api.pages.dev`，通过 Cloudflare 内部 Service binding 调用原 Workers + D1；不是任意 URL 开放代理，也没有新建第二份数据库。原 workers.dev 在当前设备网关返回不可用地址并 TCP 超时，因此以设备实际连通性为准，而不是只看 PC。不同网络仍可能不同。

本次未开通付费套餐或买域名；Pages 函数和原 Worker 仍受账号免费额度限制，免费不是无限。额度用完可能暂停云功能，本地游戏不受影响。Cloudflare 平台仍会处理基本连接信息，应用不存 IP 不等于对平台匿名。

## 验证边界

COM9 已实测迁移后开机、宠物页、两个游戏的存档/纪录菜单、Wi-Fi 配置与连接、首次分享默认关闭、带证书校验的 HTTPS 上传。云端 CHYI 宠物、蛇与方块成绩来自实际设备，未注入虚拟宠物或测试分数。

实机还验证了正常菜单移除后展示柜为空，随后重新开启分享，恢复同一随机 ID 和两个最高纪录，设备再次显示 SYNC OK / AUTO 15M。记录为蛇最高 4 食物/长度 7、方块 2114 分/10 行，都是设备真实数据。

生产状态机宿主测试覆盖保存后才上传、身份重启稳定、待发取消、离线移除保留、退避、时间校验和损坏数据保护；宿主 RTOS/网络为替身，不等于实机拔线、断电或坏证书测试。JSON、游戏只读摘要、菜单和网站网关另有回归测试。
