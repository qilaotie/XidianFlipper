# 半步电台使用手册

适用：2026-10-23 V1.0 功能扩展版，ESP-IDF 5.5.4 / ESP32-C6。当前 2 MiB 应用槽剩 556 KiB，固件指纹与验证边界见[发布说明](最终版发布说明.md)。旧设备需先备份并迁移，详见[发布与构建](发布与构建.md)。

快速了解见[功能简介](功能简介.md)，宠物完整规则见[宠物专用手册](宠物功能使用手册.md)。FUN 共 11 入口，TOOLS 共 8 项，顺序按用途组织，详见[菜单导航](menu_navigation.md)。

附近消息与游戏通过 BLE，不需路由器或 SIM 卡；Wi-Fi 是独立连接管理功能，不承载这些消息和游戏。HID 遥控期间电台暂停，使用前退出遥控。

## 1. 第一次使用

1. 给设备供电，等待进入首页，短按旋钮进入主菜单。
2. 转动旋钮选择功能，短按确认。独立按键是返回键，本文称 BACK。
3. 多机展示前，把所有设备更新到同一版固件。旧版不一定支持新游戏和新协议。
4. 发频道消息前，各设备在 `MESSAGES > Nearby room` 选择相同房间号。
5. 要显示消息发送人的昵称，先在双方 `FRIENDS > Touch to add` 完成好友添加。
6. 需要声音时，检查 `SETTINGS > Buzzer Enable` 是否开启。寻宝雷达还有自己的提示音开关。

昵称沿用设备现有配置，最多 7 个字符，展示建议用简短英文或数字。当前机身设置菜单没有新增昵称编辑器，需沿用已有配置方式提前设置。

## 2. 按键速查

| 操作 | 常见作用 | 注意 |
| --- | --- | --- |
| 转动旋钮 | 菜单选择、字符选择或数值调整 | 不同功能含义不同，参考屏幕提示 |
| 短按旋钮 | 确认、输入、提交 | 长按不等于短按 |
| 长按旋钮 | 当前页面的快捷操作 | 例如跳到 SEND、雷达声音开关、Wi-Fi 重扫 |
| 独立按键 BACK | 返回上一层或退出 | 字符输入组内先返回选组，再按才退出编辑器 |

字符编辑器的两个方向已按实机反馈反转：固件 CW 事件向前一个字符/组移动，CC 向后一个移动，列表可首尾循环。普通菜单没有一起反转。遥控器的方向见第 8 节，不要套用字符编辑规则。

## 4. 消息通信

### 4.1 频道与好友

- `MESSAGES > Nearby room`：旋转选择 1–16 号房间，短按保存。同房间用于附近群发。
- `FRIENDS > Touch to add`：两台都打开此页，把设备靠近。出现待添加对象后双方确认，等到 `Friends confirmed`。
- 好友详情可查看对象、进入快捷发送和移除好友。移除需要再次确认。
- 收件人选择页第一项是当前房间，后面是好友。选中并短按收件人，才会真正提交消息。
- 好友定向发送不等于加密私聊。本版电台通信使用明文广播协议，不适合发送敏感内容。

### 4.2 快捷短语

入口：`MESSAGES > Quick phrases`。

选择短语，短按进入收件人列表，再选择房间或好友发送。快捷短语沿用原有 10 个配置槽位，不会覆盖正在编辑的自由文字草稿。

### 4.3 自定义文字

入口：`MESSAGES > Write message`。

| 一级选项 | 用途 |
| --- | --- |
| ABC | 大写 A–Z |
| abc | 小写 a–z |
| 123 | 数字 0–9 |
| SYM | ASCII 标点 |
| SPACE | 直接输入空格 |
| DELETE | 直接删除最后一个字符 |
| SEND | 进入收件人列表 |
| EMOTES | 打开独立字符表情列表 |

操作步骤：

1. 转动选择字符组，短按进入。
2. 转动选字符，短按输入。可在当前组连续输入，每组记住上次选择位置。
3. 按 BACK 返回选组，换大小写、数字或标点。
4. 删除、空格和发送都在一级菜单，不必进第二层。
5. 长按直接选中 SEND，随后短按打开收件人列表。长按本身不会发送。
6. 选择收件人并短按，查看发送状态。

示例：发送 `Hi 8`，依次在 ABC 输入 H，在 abc 输入 i，回一级选 SPACE，再到 123 输入 8，最后 SEND。

上限是 128 个 ASCII 字符，支持英文、数字和标点，没有中文输入法。删除只删末尾，不是光标任意位置编辑。草稿保留在本次开机的 RAM 中，退出或发送后仍保留，重启后丢失。这里的文字消息不是发往手机号的运营商短信。

### 4.4 字符表情

入口：`MESSAGES > ASCII faces`，或编辑器一级菜单 EMOTES。

可选 `(^_^)`、`(^o^)`、`(^_~)`、`-_-`、`T_T`、`O_O`、`<3`。短按表情后还要选择收件人。表情独立发送，不插入、替换或清空当前草稿。

### 4.5 收件箱、昵称与发送状态

- `Inbox (n new)`：查看消息，`*` 表示未读。最多保存 32 条，列表按新消息在前显示。
- 发送者是已保存且有名称的好友时，收件箱和详情显示好友昵称。未知发送者回退显示 MAC 末尾代号，属于正常行为。
- 昵称来自本机好友记录，不能保证陌生频道发言者自动显示昵称。
- 消息详情短按可启动或停止摩斯回放，不支持摩斯的文字可能提示无法回放。
- `Last send / retry`：查看最近一次发送。失败时短按可重试。
- `Sent` 表示本机发送完成，不表示每台群发接收机都收到。好友定向发送显示 `Peer received` 才表示收到对端回执，也不表示对方已经阅读。

## 5. 摩斯电台与学习

### 5.1 MORSE LIVE

进入主菜单 `MORSE LIVE > Live Morse`。旋钮按压用于打点划，短按/长按的持续时间决定点或划，停顿完成字符识别。转动旋钮调整摩斯速度，独立 BACK 退出。

这是实时发送页面，识别出的字符会提交广播，不是先编辑完再 SEND 的草稿。演示前先在练习页熟悉按法，避免把误输入广播出去。接收设备要在相同房间，实时流与普通持久消息收件箱不是同一用法。

### 5.2 LEARN

| 项目 | 作用 |
| --- | --- |
| Free practice | 本地自由练习，不发电台消息 |
| Listen & choose | 听摩斯音，从候选字符选择答案 |
| Follow a letter | 跟着示范打出指定字符 |
| Write a letter | 听写输入字符 |

训练选择页转动选课程字符，短按开始，长按进入速度调整。练习和实时电台使用相近输入方式，但练习强制关闭发送。这些是原版已有能力。

## 6. 单机游戏

### 6.1 Answer book：答案之书

入口：`FUN > Answer book`。心里想一个问题，短按启动随机翻动并揭示英文回答，再按可重来。仅作娱乐。

### 6.2 Dice：普通骰子

入口：`FUN > Dice`。短按掷一颗 1–6 点骰子，观察动画和最终点数。BACK 退出。

### 6.3 Craps：花旗骰

入口：`FUN > Craps`。短按掷两颗骰子，以两颗点数之和判定：

| 阶段 | 规则 |
| --- | --- |
| 首掷 | 7 或 11 获胜，2、3 或 12 失败 |
| 首掷得到 4、5、6、8、9、10 | 记为目标点，进入续掷 |
| 续掷 | 再掷到目标点获胜，先掷到 7 失败，其他点数继续 |
| 结束 | 显示 WIN/LOSE，短按开始新局 |

骰面显示两颗骰子的点数，无投注、筹码或เงินจริง交易。

### 6.4 Tetris portrait：竖屏俄罗斯方块

入口：`FUN > Tetris portrait`。设备竖持，初始暂停页短按 PLAY 开始。转动左右移、短按旋转、长按直接落底。BACK 暂停/继续，暂停菜单可选 PLAY、RESET 或 EXIT。

棋盘 10 列 × 20 行，支持七种方块、消行计分、下一块预览和落点提示。每消 10 行加速，出生位置堵塞则结束。支持继续上局、最高分和最多消行数；进入默认暂停，BACK 暂停菜单 EXIT 保存退出。详见[方块](tetris.md)与[游戏存档](arcade_save.md)。

### 6.5 Snake：贪吃蛇

入口 `FUN > Snake`。新局转动选择 CLASSIC / PILLARS / GATES 三图，短按开局。游戏中短按暂停/继续、转动相对左右转向；长按进入选图，短按确认才覆盖旧局，BACK 保存退出。四边外框及实心障碍都是不可越过的墙。支持最高纪录和继续上局，旧存档为经典地图。每食物给宠物 2G；一局吃五个食物可增加一次训练胜利，门槛当时须已孵化且醒着。见[贪吃蛇手册](snake.md)。

### 6.6 Pet：电子宠物

入口 `FUN > Pet`。主界面长按查看属性；喂食、清洁、睡觉免费。PLAY 有七个子游戏，SHOP/BAG 购买与使用，DEX 查看图鉴，GROWTH 看成长，CALLS 控制提醒，CONNECT 拜访/对战，HOW TO 回看说明。

首次进入可为宠物起名，`NAME` 可改名；最多 12 个英文/数字/符号，转动选字符组、短按添加，DELETE 删除、SAVE 或长按保存，BACK 先返回分组、再取消。昵称独立保存，不影响成长和金币；联机只传前 7 字符，云端仍使用设备昵称。

每项目完整看三次说明后自动跳过，重启保留；拜访双方各 5G 加随机消耗品，每台三分钟运行时间一次。对战胜 20G、平 10G、负 6G，仅胜者加训练。详细玩法、成本和存档说明见[宠物专用手册](宠物功能使用手册.md)。方块每消一行也给钱包 5G。

## 7. 附近联机与多人游戏

联机游戏使用 BLE 游戏广播，各设备进入相同游戏，不需要先添加好友，也不需要 Wi-Fi。遥控器模式会暂停电台通信，不能一边当遥控器一边参加游戏。

### 7.1 RPS nearby：石头剪刀布（2 人）

1. 两台进入 `FUN > RPS nearby`，把希望对战的两台靠近。
2. 等待至少约 3.5 秒发现与匹配，屏幕显示对手昵称。没有昵称时回退代号。
3. 转动选择 ROCK、SCISSORS 或 PAPER，短按锁定。
4. 双方锁定后显示 WIN、LOSE 或 DRAW，以及双方出拳。
5. 按屏幕提示确认后开始新一轮，BACK 退出。

匹配依据近期平滑 RSSI 最强目标，且要求双方互相选中。“最近”是信号强弱近似，不能保证几何距离最近，多台同时匹配时建议分开站位。界面隐藏未揭晓的对方选择，但协议没有密码学防作弊。

### 7.2 Treasure radar：一藏多找

1. 一台进入 `FUN > Treasure radar`，旋转切换到 `TREASURE: HIDING`，留在此页作为宝藏端。
2. 其他设备进入同一游戏，保持寻找模式，多台可同时找同一个宝藏。
3. 寻找端显示宝藏昵称、RSSI 和信号格数。默认跟随最强目标。
4. 短按锁定/解锁当前目标，锁定时显示 `*`。
5. 长按开关提示音。越近、信号越强，滴声越急促。
6. 超过约 3 秒没有收到目标广播，显示丢失并停止旧信号声音。

音频间隔示例：-65 dBm 约 1000 ms，-40 dBm 约 260 ms，-25 dBm 及更强约 80 ms。全局 Buzzer Enable 也必须开启。

这提供“冷热”线索，不显示方向或精确米数。遮挡、朝向和环境会改变 RSSI，只能寻找主动打开 HIDING 的设备。

### 7.3 三种房间游戏的通用组局规则

适用于 Reaction party、Number bomb 和 Time guess 1-10s：

1. 一台 CREATE ROOM，其余 JOIN ROOM，按发现的可用房间加入。
2. 每局 2–4 人，房主计入人数。大厅旋转可查看玩家和准备状态。
3. 每人按下并松开旋钮准备，再按可取消准备。
4. 至少两人、全员准备，且连续 5 秒没有新人加入后自动锁定名单开赛。
5. 新人加入、取消准备或成员离开会重置等待，开赛后不能中途加入。
6. 成绩页各在线玩家确认下一局，回到大厅后重新准备。
7. BACK 退出。房主掉线不会自动选举新房主，需重新组房。

### 7.4 Reaction party：多人反应赛

进入 `FUN > Reaction party`，按通用规则组局。开赛后每台随机等待 2–5 秒，看到自己屏幕 GO 立即按旋钮。

记录本机按下时刻与 GO 的时间差，转动查看排行。GO 前按算抢按，GO 后 10 秒没按为 DNF，不参与有效名次。有效成绩同分同名次。

各机不要求同时出现 GO，无线传输时间不计入反应成绩。这是娱乐比赛，屏幕刷新和按键消抖仍有误差，不作为专业反应计时仪。

### 7.5 Number bomb：数字炸弹

进入 `FUN > Number bomb`。房主随机藏 1–100 中的一个整数，所有玩家按加入顺序轮流猜，房主先猜。

轮到自己时旋转选数，短按提交。未命中会缩小范围，交给下一位。命中者本局出局并揭晓炸弹，回合 20 秒不提交或当前玩家掉线也判出局。每局产生一位输家，不是连续淘汰到只剩一人的玩法。

### 7.6 Time guess 1-10s：盲猜随机秒数

进入 `FUN > Time guess 1-10s`。每轮随机目标是 1–10 秒的整数，所有玩家相同。

看到本机 GO 后心里默数，到目标时按旋钮停止。游戏中不显示已过时间。按与目标的绝对误差排名，提前和延后按相同误差计分，误差相同并列。

成绩示例：`7.080s E80ms` 表示用时 7.080 秒，误差 80 ms。GO 前按为抢按，GO 后 20 秒没有按为 DNF。各机在本机 GO 后计时，不依赖蓝牙包同时到达。

## 8. 蓝牙遥控器

### 8.1 配对

1. 设备进入 TOOLS 下的相应遥控页面。
2. 在电脑或手机蓝牙设置中连接 `Halfstep Remote`。
3. 等待连接就绪，打开要控制的应用并让它处于前台。
4. 用完按 BACK，设备退出 HID 遥控并恢复电台通信。

只有进入遥控页面才广播 HID 配对。遥控期间消息和游戏通信暂停。连接异常时，可在主机蓝牙设置删除旧条目再配对。不同系统和前台应用可能解释按键不同。

### 8.2 Slide remote：PPT 遥控

| 操作 | 发出的键 | 常见用途 |
| --- | --- | --- |
| 顺时针 | Page Up | 上一页 |
| 逆时针 | Page Down | 下一页 |
| 短按 | Space | 下一步动画/下一页 |
| 长按 | F5 | 从头放映，是否生效取决于软件 |
| BACK | 退出遥控 | 恢复电台通信 |

PPT 遥控已有用户实用反馈正常。展示前仍建议用实际演示电脑和文件预演，尤其是 F5 的行为。

### 8.3 Media remote：媒体遥控

顺时针音量减，逆时针音量加，短按播放/暂停，长按下一曲。媒体应用需支持系统多媒体键。

### 8.4 Camera remote：拍照兼容模式

1. 手机蓝牙连接 Halfstep Remote，解锁并打开相机，保持在前台。
2. 默认 `VOL+ 120ms`，短按发送一次按下与松开，查看手机是否拍照。
3. 旋转仅选择映射：VOL+、VOL-、ENTER、SPACE，不会立即拍照。
4. 长按仅切换持续时间：120、200、80 ms，不会立即拍照。
5. 若无反应，依次试其他映射。若只调音量或缩放，检查相机的音量键用途设置。

`KEY SENT - CHECK PHONE` 只表示按键报告已提交，不能证明拍照成功。不能自动打开相机，不能保证所有手机或第三方相机兼容。正式展示前应在目标手机上验证。

## 9. 扫描与内存工具

| 入口 | 操作与用途 |
| --- | --- |
| TOOLS > BLE scanner | 旋转选设备，短按进入 RSSI 走势，再短按切换摘要，列表长按清空，BACK 返回 |
| TOOLS > Wi-Fi scanner | 扫描附近 2.4 GHz 热点，旋转选结果，短按切换 SSID/BSSID，长按重扫 |
| TOOLS > Memory status | 查看 FREE 当前空闲堆、MIN 本次启动最低空闲堆、最大连续空闲块 |

BLE 和 Wi-Fi 各最多保留 24 条设备/热点记录。BLE 为被动扫描，部分设备可能只有地址没有名称。Wi-Fi 扫描可显示信号、信道、认证类型，扫描到某种认证类型不等于支持登录。

单独扫描页不连接热点，不保存密码。未连接 Wi-Fi 时扫描会临时暂停电台，清理完成后恢复。内存页显示的是运行 RAM，不是 Flash 剩余容量。

## 10. Wi-Fi 连接

入口：`TOOLS > Wi-Fi connect`，建议演示使用 2.4 GHz WPA2 手机热点。

1. 选 Scan / choose Wi-Fi，扫描后核对 SSID，选择自己的热点。
2. 加密热点打开掩码密码编辑器。字符组操作与消息编辑器一致，已输入内容只显示星号。
3. BACK 回到选组。长按跳到 CONNECT，再短按提交。
4. 等待认证和 DHCP，看到热点名、有效 IPv4 和 CONNECTED 表示连上局域网。
5. 退出页面不会主动断开连接。

| 选项 | 作用 |
| --- | --- |
| Connection status | 查看热点、IPv4、信号或失败原因 |
| Connect saved | 连接已保存的一组网络 |
| Disconnect | 断开，保留保存记录 |
| Forget saved | 二次确认后断开并删除该 Wi-Fi 配置 |
| Auto reconnect | 默认 OFF，可选择开机自动连接 |

支持开放网络和普通 WPA/WPA2，以及可回退到 WPA2 的混合网络。不支持纯 WPA3、WEP、企业认证或手填隐藏 SSID。密码支持 8–63 个可打印 ASCII 字符，或 64 位十六进制 PSK。

只有拿到 IP 后才保存新网络，失败的输入不覆盖旧记录。保存位置是设备本地独立 NVS，当前没有启用 Flash/NVS 加密，不应当作密码保险箱。勿在 PPT、截图或录屏中展示真实密码。

已在 COM9 上确认连接用户指定热点并取得 IPv4。该测试证明认证与 DHCP 成功，不证明互联网访问、保存网络重连、忘记网络或 Wi-Fi 在线时多人游戏全部通过。

当前支持可选云端分享，但不提供联网聊天、网页浏览或 OTA。Wi-Fi 在线与 BLE 有共享无线资源，可能影响通信响应，应在实际环境测试。

### 10.1 Cloud sync：在线排行与宠物展示柜

先连能上网的热点，再进入 `TOOLS > Cloud sync`。默认 SHARE OFF，长按切换分享；开启后短按可立即同步，在线时也会定期同步。上传公开宠物属性摘要、设备昵称和方块/蛇最高分，不上传消息、热点密码或完整棋局。访问[半步小岛](https://qilaotie.github.io/XidianFlipper/)查看。

关闭分享只停止后续上传；要移除现有公开内容，转到 REMOVE ONLINE 并长按。离线时会保存移除意图，之后联网重试，重启保留。SYNC OK 代表最近请求成功；不是完整存档云备份，不能从网页恢复棋局。详见[云端说明](cloud_community.md)。

## 11. 设置与维护

- Disp Bri：屏幕亮度。
- Btn SPT / Btn LPT：短按与长按判定相关参数，改动会影响操作手感。
- LED Enable / Buzzer Enable：全局灯光和蜂鸣器开关。
- Morse WPM：摩斯速度。
- Text Scroll：长文本滚动设置。
- Screen / power：立即关屏或进入深睡相关操作。深睡不是边通信边息屏，展示时建议保持唤醒。
- Factory Reset：恢复出厂设置，有清除配置的风险，正常展示不要操作。

修改前先记下参数，演示时避免更改按键阈值或执行恢复出厂。固件升级应使用配套镜像和既有分区，不要随意整片擦除。

## 12. 常见问题

| 现象 | 检查 |
| --- | --- |
| 消息只显示代号 | 对方是否已保存为有昵称的好友，是否只是陌生频道发送者 |
| 收不到消息或游戏搜不到 | 相同版本/游戏，频道消息用相同房间，退出 HID 遥控，等待扫描清理 |
| 雷达没声音 | Buzzer Enable、雷达长按声音开关、宝藏是否仍在 HIDING、目标是否丢失 |
| 靠近后数值并不连续上升 | RSSI 受姿态、人体和墙壁影响，调整朝向并慢慢移动 |
| 多人比赛没开 | 至少两人、全部准备、5 秒没有新人或状态变动 |
| 找不到 Halfstep Remote | 先进入遥控页面，再在主机刷新蓝牙列表 |
| 拍照只调音量 | 检查相机音量键用途，试其他映射，兼容性需目标手机实测 |
| Wi-Fi 连接失败 | 热点频段、认证方式、密码、信号，查看屏幕 reason |
| 重启后草稿消失 | 草稿仅在 RAM，属于当前设计 |
| 显示 Sent 但对方没收到 | 群发没有逐人确认，先靠近、同房间重试，好友回执看 Peer received |

## 13. 展示前检查

- 所有参赛设备同版，贴好便于辨认的昵称/编号。
- 两台先完成好友添加，验证带昵称消息。
- 先测两人游戏，再扩展到三四人。现有记录中的四人流程是宿主模拟，不能当四台射频实测。
- 预先给电脑配好 PPT 遥控。不要在游戏中途切到遥控。
- 热点使用演示专用密码，准备一张不含密码的 CONNECTED 截图。
- 不临场改按键阈值，不恢复出厂，不整片擦除。
- 展示结束退出遥控；不需要联网时断开 Wi-Fi。
