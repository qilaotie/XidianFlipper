# 准备房间与直接牌桌（2026-10-31）

创建或加入游戏桌后直接显示准备界面。上方是游戏与已准备人数，中间每个框代表一个座位：填充标记表示已准备，下划线表示本机座位。旋转选中座位可看昵称和准备状态；默认选中自己的“准备”按钮，短按切换准备。

主机从准备按钮向前旋转一步是“开始”，再一步是邀请。所有人准备且达到最低人数才能开局。普通成员可旋转到规则或离开确认，观战者不能准备或开局。新人加入时焦点保持原操作，不会因人数变化意外切换到其他按钮。

开局后十款游戏自动进入对应界面，不必再到房间菜单选“公共桌面”或“执行操作”：UNO 显示牌桌，情书/骗子酒馆显示手牌背面，达芬奇密码显示其他玩家牌位，快艇骰子显示骰子，井字棋显示九宫格，身份类显示玩家席位及当前阶段。手牌/身份继续长按查看，避免泄露。身份类与达芬奇密码在图形桌面长按可查看自己的私密内容；返回房间可重新选择公开桌面。

图形界面旋转选择、短按操作；需要目标/数字/确认的卡牌仍在图形步骤里完成。身份类的部分复杂行动仍会进入已有行动表单，不能理解为本次重写了全部游戏操作。返回键保留房间管理入口，返回后不会强制再次跳进牌桌。

宿主测试覆盖全部十款的自动入口、讨论/组队/夜晚阶段、准备人数门槛、同步与过期保护、观战只读、手牌隐私和 128×32 绘制范围。实机情况另以本轮实际记录为准。

本轮同时修复准备页及卡牌目标/数字选择器的空闲按键判定：真实固件逆时针编号为 0，空闲哨兵改为独立值。回归直接核对固件按键定义，检查多帧静置时焦点、猜测值保持不变。

## 本轮设备验证

COM9、COM10、COM15 已更新同一固件，应用回读一致，分区表和两处 NVS 在首次启动前与更新备份一致。情书、UNO、达芬奇密码双机检查通过；骗子酒馆和谁是卧底三机准备、状态同步及开局自动进入牌桌通过。手牌先隐藏、长按显示已检查；谁是卧底在讨论阶段自动显示三人席位。快艇骰子双机自动进入骰子界面、井字棋双机自动进入完整棋盘通过。

这些是本次真实按键和屏幕/状态检查，不代表十款完整实机对局全部验收；阿瓦隆、一夜狼、狼人杀的所有阶段主要由生产代码宿主回归覆盖。测试短按必须小于设备 300ms 长按阈值，脚本使用 100ms，长按查看单独保持 1.8 秒。

## 达芬奇密码同页快捷查看

公共牌桌上旋转查看对手牌位，短按猜牌。长按直接显示自己的手牌和本轮新牌，再长按回到公共牌桌；手牌页按返回也回到公共牌桌，不退出房间。两个视图分别记住光标，例如看对手第六张时切到自己的第二张，再切回仍是原对手第六张。

猜牌过程中长按查看自己的牌会取消尚未提交的本次猜测，不发送操作；回来后重新选择数字和确认。查看不要求轮到自己，观战者仍只能查看公开牌位。公共牌桌的结束猜测按钮继续保留。短按自己的手牌不会误发猜测。

快捷查看已在 COM9 / COM10 真实双机验证：两台都在同一对局页面完成手牌/公共牌位切换，切回后公开牌桌画面与切换前逐字节一致，手牌页返回也回到原牌位；查看前后游戏修订号不变，没有提交游戏操作。测试后结束测试局并恢复网络开关。COM15 已更新同版应用，但本项快捷查看未在第三台重复实测。

## 同房再来一局

一局结束后直接显示结果和重新准备按钮，保留原房间、玩家和座位。所有人（包括主机）重新准备，主机旋转到开始再短按，即可开启下一局；不用重复找房、加桌。准备不齐或人数不足不能开局，观战者不能准备或开局。

下一局重新洗牌、分配身份、清空棋盘/分数/投票，私密界面重新隐藏。结算页可以查看上局结果，返回回到准备页。结果与准备同步期间等待更新，结束后离线的成员也需要上线准备。房间是 RAM 会话，主机重启或切频道仍会结束。

同房续局需参与设备更新到支持本功能的同版固件。没有增加持久存档字段或更改 NVS 布局；房间/准备仍是内存状态。

同房续局已在 COM9 / COM10 实际完成两局井字棋：第一局正常获胜结算，未准备时开局被阻止，双方重新准备后主机开启第二局，两个座位保留且棋盘清空；第二局再次正常获胜结算。过程中没有重新找房或加入。COM15 已更新同版固件；其续局未单独重复实测。其他九款同房重开由生产代码宿主回归覆盖，不等同于完整实机对局。
