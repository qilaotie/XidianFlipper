# 消息管理与实时协作

协作菜单现已补齐中文，可在设置中切换语言，题目/任务沿用 ASCII 编辑器。参与设备需同版、同频道，并在“工具 → 自组网状态”开启 MESH；重启后默认关闭。新增签到、抢答、诊断和持久结果记录见[后续协作功能](crowd_activities.md)。下文保留英文菜单名，方便与英文界面对照。

## 消息管理

消息首页 → Message management，可筛选全部、未读、当前频道、指定好友、公告。好友分类只包括收到的消息，不是包含发送记录的完整聊天历史。仍使用原有 32 条持久化收件箱。

打开消息后长按滚轮：Reply with draft 使用现有草稿回复；Quote and reply 在草稿开头插入发送者代号和原文前 16 字符；Delete this message 二次确认后删除单条。短按原消息仍播放摩斯音。引用空间不足或保存失败时保留原草稿，引用只是普通文字。

好友默认私信回复；非好友公共消息回复到原频道，发送时必须仍在该频道。公告发送者不是好友时需先加好友才能回复。发送有确认页；离开编辑器退出回复模式。工作草稿和常用草稿保持不变。

## 多人投票

消息首页 → Multiplayer poll → Create poll from draft。编辑 1～48 字符题目，点击 Options 在 2、3、4 个选项间循环，预览并确认。选项固定 A/B/C/D，可在题目写明含义，例如 `Lunch A:rice B:noodle`。

其他设备打开同菜单即可发现投票。点击 Vote A/B/C/D，房主接受后才确认。每个设备标识一票，不能改票，最多 8 台，创建者也可投票。房主可确认关闭，结果保留显示。

## 组队任务板

消息首页 → Team task board → Create / add from draft。草稿作为 1～18 字符任务名称，预览新板并确认后成为房主；Add task to my board 向自己已有的板追加，最多四项。

OPEN 可领取，TAKEN 已领取，DONE 已完成。打开任务后 Claim task 领取；领取者用 Mark completed 完成或 Release task 释放。抢同一任务由房主先接受的有效请求获胜；过期版本请求会拒绝，查看最新板后再操作。完成任务没有额外宠物金币。

## 联系人状态

好友列表 `[D]`：15 秒内直接听到；`[R]`：60 秒内听到过，可能经过中继；`[?]`：状态未知。好友详情 → Contact status 可看观测时间、跳数或直连 RSSI；Received from friend 查看该好友发来的消息。

无线观测不能保证此刻在线，未发现也不代表确定离线。中继的 RSSI 不会当作原发送者的直连信号强度。状态缓存重启清空。

## 会话与可靠性边界

- 同时一个投票和一个任务板。房主每约 2 秒广播。同频道已发现的新鲜会话不会被其他房主覆盖，15 秒未更新后才可能发现新房主。本机主持的活动不会被远端覆盖；新建替换需确认。
- 活动保存在 RAM，重启或切频道结束；没有断电恢复或房主选举。关闭 MESH 停止发送并取消等待，旧视图保留；重新开启可恢复本机尚存的广播。
- 远端操作先显示 Waiting for host ACK，最多发送六次、等待八秒。Host confirmed 才表示接受；No ACK 表示结果未知，需查看房主状态，不能当作必然失败。快照可能稍晚于确认到达。
- 房主按设备、启动会话和请求序号去重；任务操作检查板版本，领取者才可完成/释放。最近请求表 16 项，投票设备表八项。
- 新增 v3 类型 15，同频道 ROUTED 广播，沿用最多三段链路；旧固件不能参与。CRC 和设备标识不提供身份认证，适合可信的小范围试验。
- 两台实机验收不能代替三台设备的真实中继验收。

## 验证入口

`tools/test_team_activity.c` 测真实核心的重复请求、确认、任务争抢、权限、版本、频道和状态衰减；`tools/test_message_management.py` 测筛选、引用保存失败/溢出、取消和回复频道保护。实机证据另行记录。
