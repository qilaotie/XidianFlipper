## 已知限制

- 自由输入与说明使用 ASCII 字库，不支持中文输入法。
- 消息不是手机短信，定向不等于加密私聊；游戏无密码学防作弊。
- 宠物没有婚育、疾病治疗、手动转赠，不与正版玩具互联。
- 拜访先写冷却再入账，避免断电重领；中途断电可能丢此次奖励。
- Wi-Fi 用于连接与可选云分享，不承载附近对战。没有 IR、NFC/RFID、Sub-GHz 或 OTA。
- 云分数为设备自报，不防作弊；没有云端完整存档恢复。关闭分享不撤下既有公开内容，须 REMOVE ONLINE。
- 宠物昵称最多 12 个 ASCII 字符，联机只发前 7 字符；云端仍使用设备昵称。
- 旧设备必须先按迁移流程备份并扩槽，不能单刷分区表或超旧槽的大应用。

升级见[发布与构建](发布与构建.md)。不混用镜像，不整片擦除已有设备；遇到 SAVE ERROR 保留数据排查，不自动清档。第三方组件许可证保留。
