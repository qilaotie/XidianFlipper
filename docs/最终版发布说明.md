## 交付功能

见[功能简介](功能简介.md)。保留附近消息、摩斯、学习、好友和原有单机玩法；新增自由文字/表情、八个独立游戏、Pet 和七项工具。FUN 合计 11 个入口，宠物子游戏不重复计数。

宠物说明完整看三次后直达，HOW TO 随时回看；拜访双方各 5G 加随机消耗品，每台三分钟运行时间冷却；对战胜 20G、平 10G、负 6G，仅胜者加训练。元数据独立保存，重启、新蛋不清除引导或冷却。宠物载荷版本 2，双方一起更新。

## 已知限制

- 自由输入与说明使用 ASCII 字库，不支持中文输入法。
- 消息不是手机短信，定向不等于加密私聊；游戏无密码学防作弊。
- 宠物没有婚育、疾病治疗、手动转赠，不与正版玩具互联。
- 拜访先写冷却再入账，避免断电重领；中途断电可能丢此次奖励。
- Wi-Fi 只做连接与管理，无 IR、NFC/RFID、Sub-GHz、V1.5 OTA。
- 应用槽接近满载，后续功能须先评估体积。

升级见[发布与构建](发布与构建.md)。不混用镜像，不整片擦除已有设备；遇到 SAVE ERROR 保留数据排查，不自动清档。第三方组件许可证保留。
