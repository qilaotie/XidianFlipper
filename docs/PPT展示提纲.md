# 半步电台 PPT 展示提纲

适用于 2026-10-23 当前发布。以下是制作 PPT 的文案提纲，不是已生成的 PPTX。数据及实机/宿主证据边界以[发布说明](最终版发布说明.md)为准。

## 第 1 页：项目定位

标题：半步电台——附近沟通、互动游戏与电子宠物。
一句话：用 ESP32-C6、OLED 和旋钮完成无需手机的近距离互动。
不要将其称为完整 Flipper Zero 或互联网聊天终端。

## 第 2 页：系统组成

硬件：ESP32-C6、128×32 OLED、旋钮/返回键、声光反馈。
软件：ESP-IDF 5.5.4；自定义 BLE 广播承载附近消息和游戏；BLE HID 连接电脑/手机；Wi-Fi 做连接管理和可选 HTTPS 云分享。HID 遥控期间电台暂停，不能画成所有模式同时满速运行。

## 第 3 页：消息与摩斯

展示快捷短语、自由 ASCII 编辑、字符组、一级删除/发送、字符表情、好友昵称。
原有摩斯电台和学习功能保留。
边界：非中文输入法，非运营商短信，非加密私聊。

## 第 4 页：单人与多人游戏

FUN 共 11 入口：原版两项 + 新增八个独立游戏 + Pet。
展示方块消行动画、蛇三地图与清晰墙体、两款游戏保存/续局、附近石头剪刀布、一藏多找、多人反应赛、数字炸弹、随机秒数。
人数：双机、2–4 人房间或多寻找端；四人模拟不等于四台射频全部通过。

## 第 5 页：宠物养成闭环

用户起名 → 照顾 → 成长分支 → 游戏赚币 → 商店/装饰 → 图鉴 → 新蛋继承。
四阶段、三成年分支、七子游戏、七种商品、六项图鉴。
需求提醒、自主动作；说明完整看三次后跳过，HOW TO 随时回看。
不要在现场误确认 NEW EGG 退役现有宠物，进化需提前养成。

## 第 6 页：宠物社交与激励

拜访：双方各 5G+随机消耗品，每台三分钟正常运行时间一次，重启不清冷却。
对战：胜 20G / 平 10G / 负 6G；仅胜者加训练；异常退出不领奖。
展示双方昵称、确认开局、比分与钱包。它是本设备改编玩法，不与正版拓麻歌子互联。

## 第 7 页：工具展示

八工具：PPT / 媒体 / 拍照遥控、Wi-Fi 连接、云同步、Wi-Fi 扫描、BLE/RSSI、内存。
现场优先演示已在目标电脑预演的 PPT 翻页。
KEY SENT 不等于拍照成功，CONNECTED 不等于互联网连通，RSSI 不等于方向和距离。

## 第 8 页：工程与验证

应用 1,527,808 字节，2 MiB 应用槽余 569,344 字节（556 KiB）。
旧三槽迁移为 USB 单应用布局，保留两处 NVS 物理位置、NVS v7 和 storage ABI 1；先双读备份，写后整片校验。不存在 OTA 回滚保证。
当前实机：COM9 命名、三地图、名字与地图重启恢复。先前云版本实机：HTTPS 上传、撤下和重分享。社交与四人场景区分历史实机与宿主测试，不能宣称最新版本全部验收。

## 第 9 页：半步小岛在线社区

打开 https://qilaotie.github.io/XidianFlipper/ 展示排行榜和宠物展示柜。设备默认不分享，用户连 Wi-Fi 后主动开启，上传属性摘要与最高分，不上传私信、密码或完整棋局。HTTPS 校验证书，设备独立身份/凭证，不公开 MAC。
关闭分享只是停止后续上传，要撤下须 REMOVE ONLINE；设备自报排名不是防作弊比赛。本机宠物昵称与云端设备昵称暂时独立。先前版本的真实上传记录不要描述成所有新功能均已联网验收。

## 建议现场顺序

1. 提前统一固件、好友与简短昵称，宠物喂饱、清洁、休息后唤醒。
2. 发送带昵称的自编消息。
3. 展示宠物游戏、钱包和装饰；再双机拜访/对战，等双方结算。
4. 切 PPT 遥控翻页，结束后退出 HID。
5. 不操作出厂重置、不整片擦除、不展示真实热点密码。

## 证据和答辩

内部截图与日志在 build，各子目录只证明对应历史构建。公开 PPT 选非敏感截图，遮掉 SSID/IP/MAC 等不必要身份信息，不上传原始日志。正式素材库应独立保存，不依赖本机 build。

- 为什么不用 Wi-Fi 也能通信？使用附近 BLE 广播。
- 为什么不称蓝牙 Mesh？当前是自定义消息应用，不等同标准 Bluetooth Mesh。
- 是 Flipper 吗？无 IR、NFC/RFID、Sub-GHz，不是完整替代。
- 怎么保护数据？正常维护保留 NVS，发布不带运行数据；当前凭据未启用 NVS 加密。
- 四人都测了吗？四实例逻辑覆盖，四台实机仍需专项验收。
- 后续空间够吗？当前 2 MiB 应用槽剩 556 KiB，仍须分别评估 Flash、运行 RAM 和耗电；扩大应用槽不等于增加 RAM。
