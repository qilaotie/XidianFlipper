# 发布、构建与烧录

## 编译

Windows / PowerShell，ESP-IDF **5.5.4**，ESP32-C6 / 4 MiB Flash。SDK 工具链另行安装；仓库包含本机需要的组件源码。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -IdfPath 'C:\esp\v5.5.4\esp-idf' -IdfToolsPath 'C:\Espressif' -IdfPythonEnvPath 'C:\Espressif\tools\python\v5.5.4\venv'
& 'C:\Espressif\tools\python\v5.5.4\venv\Scripts\python.exe' tools/verify.py
```

改成自己的工具链路径，SDK 必须匹配。正式入口是 build.ps1，普通 idf.py build 不替代发行核验。VS Code 打开仓库目录，不打开混合上级目录。

## 目录与产物

- firmware / main / components：当前源码和组件许可证。
- docs：文档；tools：构建、宿主测试与真实设备操作脚本。
- releases/original：冻结原版，不修改、不覆盖。
- [releases/final-2026-10-22](../releases/final-2026-10-22/README.md)：本次最终版配套镜像和核验记录。
- build/release：最新本机构建，不提交整个 build 缓存。

同一发行包的 manifest.json、四段镜像与 validation 配套记录必须一起核验，不混用早期分区表和新 app。改变编译输入后重新构建。

## 烧录与数据保护

先核对芯片、串口、当前布局和启动槽，关闭串口监视器。以下命令在配套发行包目录运行，仅适用于本项目已验证的布局。

首次安装四段镜像：

```powershell
python -m esptool --chip esp32c6 -p COM9 -b 460800 write_flash --flash_mode dio --flash_size 4MB --flash_freq 80m 0x0 firmware/bootloader.bin 0x8000 firmware/partition-table.bin 0xf000 firmware/ota_data_initial.bin 0x20000 firmware/app.bin
```

写初始 OTA 数据会改变启动选择，已有设备不要随便套用首次安装流程。其他型号、其他分区或 V1.5 不适用。

确认正在运行 factory 槽 0x20000 的同布局维护设备，可只更新 app：

```powershell
python -m esptool --chip esp32c6 -p COM9 -b 460800 write_flash --flash_mode dio --flash_size 4MB --flash_freq 80m 0x20000 firmware/app.bin
```

若正在其他 OTA 槽，不能假设写 factory 就会执行新程序，应先核查启动状态。不擅自 erase_flash：整片擦除会破坏好友、Wi-Fi、宠物和配置。正常维护不需擦除 NVS。

## 测试

构建后先 verify.py，常用宿主回归：

```powershell
python tools/test_pet_service.py
python tools/test_pet_link.py
python tools/test_pet_notice.py
python tools/test_menu_layout.py
python tools/test_tetris_ui.py
python tools/test_snake_ui.py
python tools/test_tool_reports.py
```

部分脚本需系统 GCC。它们运行生产逻辑及存储/无线/时钟替身，不替代射频、声音、按键手感、手机兼容或断电实测。smoke_*.py 使用真实 USB 控制，可能实际花币、照顾、扫描或配对；先读脚本再运行，不当成无副作用的单元测试。

## 可选网页与公开发布

相邻 ../WEB 是独立工作空间，本仓库不含网页；启动网页.cmd 仅为可选入口。没有 WEB 仍可独立编译和 esptool 烧录。本版没有 V1.5 OTA，不伪装协议字段。

公开包不含 build 缓存、旧构建备份、串口日志、实际 NVS 转储、热点截图、密码、令牌。保留冻结基准、许可证和真实验收边界。固件只分发程序镜像，不复制某台设备运行数据区。上传前确认仓库链接与隐私设置。
