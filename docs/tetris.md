# 竖屏俄罗斯方块

2026-10-23 本地版新增最高分/最多消行数与继续上局，暂停顶栏 BEST 查看纪录、CONT 继续、NEW 新局、EXIT 保存退出。读档默认暂停，详见[游戏存档](arcade_save.md)。下方原构建与验收记录是历史快照。

入口：`FUN > Tetris portrait`（单机游戏组）。将设备竖持，使 TETRIS 标题朝上。只旋转游戏绘制，退出后菜单仍为横屏。

## 操作

- 进入后先暂停，旋转选 PLAY、短按开始。
- 游戏中旋转：左右移动，固件 CW 向右、CC 向左。
- 短按旋钮：顺时针旋转方块。
- 长按旋钮：立即落到底并锁定，不需要一直等自动下落。
- BACK：暂停/继续。暂停时可旋转选 PLAY（继续）、RESET（新局）或 EXIT（退出），短按确认。
- 结束时显示 OVER，选 NEW 或 RESET 开新局，EXIT 退出。

暂停页提示：TURN LR 是旋转左右移，TAP ROT 是短按旋转，HOLD DN 是长按落底。

## 规则与显示

10 列 × 20 行棋盘，七种四格方块，七袋洗牌抽取。横行填满会消除，1/2/3/4 行分别得 100/300/500/800 分，再乘以当前等级。长按落底每下降一格加 2 分。

上方显示累计得分、L（累计消行数）和 NEXT（下一块）。虚点显示当前方块落点。每消 10 行提高一档速度，自动下落由 820 ms 最快降到 120 ms。

新方块出生位置被占用则结束。支持简单水平踢墙，不是完整 SRS 竞技规则，没有暂存方块、联网对战、排行榜或持久化最高分。暂停会冻结自动下落，重新进入会新开一局。分数和进度只在 RAM。

消行时满行闪烁 3 次，共约 360 ms，然后显示消行后上方方块落下的棋盘。动画期间暂不接受移动、旋转和硬降，防止误操作下一块；BACK 仍可暂停，暂停也冻结动画。动画结束后重新计算下一块的下落等待时间。

棋盘针对 32×128 竖屏使用 3×4 像素格，保留方块间隔，不引入图片或大字体资源。原有其他游戏全部保留，不改变分区、NVS 或 storage ABI。

## 验证

- `tools/test_tetris.c`：生产逻辑，方块格数、七袋随机、边界/踢墙、2/4 行消除、计分、出生堵塞、速度和 50,000 次操作不变量。
- `python tools/test_tetris_ui.py`：编译生产页面并模拟绘制/按键，验证每次绘制不越界、暂停/继续、硬降、重开、退出、重入及 20,000 次渲染输入，生成宿主截图。这不是实机验收。
- `python tools/smoke_tetris.py --port COM9`：经 USB 驱动真实菜单，采集竖屏/暂停/退出/重入屏幕，记录在 `build/tetris-smoke/`。它会开始和操作一局，但不修改持久设置，也不等于真人长时间游玩验收。

编译和发布校验沿用根目录 `build.ps1` 与 `tools/verify.py`。
