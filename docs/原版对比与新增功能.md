# 原版对比与新增功能

截至 2026-10-22 的最终快照，构建数据见[发布说明](最终版发布说明.md)，完整功能见[功能简介](功能简介.md)。

## 对比基准

原版为冻结的 releases/original/source，标签 v1.0.0-noautosleep，基准提交 `4c7f204f5aa9290c303f20f3d262f4cf6774d5f8`。当前为本工作区 ESP-IDF 5.5.4 / ESP32-C6 功能扩展版，不代表其他硬件或 V1.5。两者版本字符串相同，实际构建用清单和哈希区分。

## 保留与新增

| 模块 | 原版保留 | 当前扩展 |
| --- | --- | --- |
| 消息 | 快捷短语、房间、收件箱、回执/重试、好友定向 | 128 字符 ASCII 编辑、字符组、一级编辑/删除/发送、7 种字符表情、好友昵称 |
| 摩斯与学习 | 实时摩斯、自由练习、听音选字、跟练、听写 | 保留，不重复算新增 |
| 好友 | 近距离发现、确认、保存、查看、移除 | 消息身份展示更友好，陌生者仍可显示代号 |
| FUN | Answer book、Dice 两项 | 八个独立游戏加 Pet，合计 11 入口 |
| TOOLS | 无此一级入口 | 遥控、网络、扫描、内存七项 |
| 系统 | 设置、声光、深睡、USB 投屏/控制等 | 菜单按用途排序、长描述滚动、按键及遥控方向调整 |

旧源码存在过时注释或空桩，以上以实际路由与运行逻辑为准。原有 USB、好友、摩斯不包装成全新开发。

## 新增游戏与宠物

八个独立游戏：花旗骰、附近石头剪刀布、寻宝雷达、多人反应赛、数字炸弹、随机 1–10 秒盲猜、竖屏俄罗斯方块、贪吃蛇。

Pet 包含四阶段/三成年分支、免费照顾、需求提醒、自主动作、七子游戏、金币与七种商品、背包/装饰/图鉴、新蛋继承、双机拜访及对战。方块每行 5G、蛇每食物 2G 联动钱包。说明完整看三次后直达，HOW TO 随时回看。

拜访双方各 5G+随机消耗品，每台三分钟运行时间一次；对战胜 20G、平 10G、负 6G，仅胜者增加训练。详细规则见[宠物手册](宠物功能使用手册.md)。

多人版迭代不重复算新游戏，Pet 子游戏不重复算 FUN 一级入口。三种房间游戏最多四人；寻宝支持多寻找端，不承诺无限容量。

## 七项工具

PPT、媒体、拍照兼容遥控，Wi-Fi 连接、Wi-Fi 扫描、BLE/RSSI 扫描、内存状态。拍照支持映射/按键时长选择，不保证所有手机；Wi-Fi 是连接和管理，不是联网聊天；扫描不是破解或协议嗅探。

## 空间与兼容

| 指标 | 冻结原版 | 当前最终版 |
| --- | ---: | ---: |
| 芯片 Flash | 4 MiB | 4 MiB |
| 单应用槽 | 1,245,184 字节 | 1,245,184 字节 |
| 应用镜像 | 768,016 字节 | 1,238,800 字节 |
| 单槽剩余 | 477,168 字节 | 6,384 字节，约 6.2 KiB |
| 分区/全局存储 | 既有布局 | 保持 NVS v7 / storage ABI 1 |

相对原版增加 470,784 字节，应用槽约占 99.5%，不是整片 Flash 占用率。运行 RAM 随模式改变，以 Memory status 为准。
