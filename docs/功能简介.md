# 半步电台功能简介

截至 2026-10-22 的 V1.0 功能扩展版。操作见[使用手册](使用手册.md)，构建指纹见[最终版发布说明](最终版发布说明.md)。

## 一句话介绍

用 ESP32-C6、小 OLED 和旋钮，把附近沟通、摩斯学习、朋友间小游戏、电子宠物和日常遥控放进随身设备。

## 模块全景

| 模块 | 能力 | 要求 |
| --- | --- | --- |
| MESSAGES | 快捷短语、自由 ASCII 编辑、字符组、表情、频道、好友定向、收件箱和发送状态 | 附近同版设备，频道消息用同一房间 |
| MORSE LIVE | 实时摩斯输入、接收和声音反馈 | 附近设备，非互联网电台 |
| LEARN | 自由练习、听音选字、跟练、听写 | 单机 |
| FRIENDS | 近距离发现、双方确认、保存/查看/移除，消息昵称 | 双方添加，陌生者可能显示代号 |
| FUN | 单机、双人、多人游戏和宠物 | 见下表 |
| TOOLS | HID 遥控、Wi-Fi、无线扫描、内存 | 遥控需配对，Wi-Fi 需适配热点 |
| SETTINGS / ABOUT | 显示、按键、声光、摩斯速度、滚动、关屏/深睡、设备信息 | 单机 |

## FUN：11 个入口

| 项目 | 人数 | 玩法 |
| --- | --- | --- |
| Pet | 单机养成、双机社交 | 成长、游戏、金币、商店、装饰、图鉴、拜访和对战 |
| Tetris portrait | 1 | 10×20 竖屏方块、落点预览、暂停、消行动画，每行赚宠物 5G |
| Snake | 1 | 横屏贪吃蛇、旋转相对转向、暂停，每个食物赚宠物 2G |
| Answer book | 1 | 随机英文回答 |
| Dice | 1 | 普通骰子 |
| Craps | 1 | 双骰、首掷与目标点、胜负判断 |
| RPS nearby | 2 | 附近匹配、昵称、锁定出拳、揭晓 |
| Treasure radar | 一藏多找 | 藏宝广播、信号冷热与渐密声音，不是方向雷达 |
| Reaction party | 2–4 | 全员准备、五秒稳定窗口、反应计时和排行 |
| Number bomb | 2–4 | 1–100 数字炸弹、轮流猜、范围收缩与超时 |
| Time guess 1-10s | 2–4 | 随机 1–10 秒目标，盲计时并按误差排名 |

计数口径：原版两项（Answer book、Dice），新增八个独立游戏和一个 Pet，共 11 入口。Pet 子游戏和双人/多人迭代不重复算一级入口。

## 宠物：照顾—成长—游玩—社交

- 四属性：饱食、心情、精力、清洁；免费喂食、清洁、睡觉，不设死亡。
- 蛋、幼体、少年、成年四阶段；正常运行累计 30 分钟成年，按训练和照顾分 SPORT / SUNNY / MELLOW，成年后定型。
- 需求提醒和自主动作：眨眼、走动、跳跃、挥手、睡眠呼吸，声音受宠物与全局开关控制。
- 七游戏：接音符、相扑、举旗、顶皮球、记忆、赛跑、快速反应，单人获胜 8G。
- 七种商品、消耗品、永久玩具、三种装饰、六项图鉴；新蛋继承钱包、背包和收集。
- 每项目完整看三次说明后自动跳过，HOW TO 随时回看，计数跨重启保留。
- 拜访双方各得 5G 与一件随机消耗品，每台每三分钟正常运行时间一次；选中物品满则只给金币。
- 双机随机相扑、顶球、赛跑；胜者 20G、平局各 10G、败方 6G，仅胜者加训练。先消耗游戏体力，异常中断不领奖。

本机轻量实现，不与正版拓麻歌子互联，没有婚育、疾病治疗或手动转移背包物品。详见[宠物手册](宠物功能使用手册.md)。

## TOOLS：7 项工具

| 项目 | 功能 | 边界 |
| --- | --- | --- |
| Slide remote | PPT 翻页、Space、F5 | 依赖前台软件；暂停电台 |
| Media remote | 音量、播放暂停、下一曲 | 依赖媒体键支持 |
| Camera remote | VOL+/VOL-/ENTER/SPACE、多种时长 | 目标手机和相机需实测 |
| Wi-Fi connect | 选网、掩码输入、认证/DHCP、保存、重连、断开、忘记 | 2.4 GHz、支持的开放/WPA/WPA2 模式，非浏览器 |
| Wi-Fi scanner | 热点、信号、信道、认证类型 | 扫描不获取密码 |
| BLE scanner / RSSI | 广播列表、走势、名称/厂商/服务摘要 | 非完整 GATT 浏览器或嗅探器 |
| Memory status | 当前/最低空闲堆和最大连续块 | 运行 RAM，非 Flash |

## 展示建议与限制

先演示好友昵称消息，再用宠物游戏赚币、买装饰、拜访和对战，最后切 PPT 遥控实际翻页。退出遥控后再演示电台。

四人逻辑测试不等于四台射频验收；CONNECTED 不等于上网；KEY SENT 不等于已经拍照；RSSI 不等于精确距离。无线消息非加密私聊，不提供 Flipper 的 IR、NFC/RFID、Sub-GHz 能力。当前应用槽仅剩约 6.2 KiB，不含大型中文字库或 V1.5 OTA。
