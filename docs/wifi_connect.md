# Wi-Fi 连接（首版）

入口：`TOOLS → Wi-Fi connect`（遥控器组之后）。这版连接 2.4 GHz Wi-Fi，获取 IPv4 地址；不包含联网聊天、网页服务、OTA 或互联网连通性测试。拿到局域网 IP 不代表能上互联网。

## 连接 Xiaomi_6C64 或其他热点

1. 手机热点设成 **2.4 GHz、WPA2**，保持开启。
2. 设备进入 `Scan / choose Wi-Fi`，选中热点。扫描只在明确操作后发生，不会自动连接陌生热点。
3. 加密热点打开密码编辑器：转旋钮选择 `ABC / abc / 123 / SYM / SPACE / DELETE / CONNECT`；短按进入字符组并输入，BACK 回选组。长按直接跳到 CONNECT，再短按提交。
4. 密码已输入部分只显示星号。新密码 8–63 个可打印 ASCII 字符，或 64 位十六进制 PSK；开放热点无需密码。支持普通 WPA/WPA2 和可回退 WPA2 的 WPA2/WPA3 混合热点，不支持纯 WPA3、WEP、企业认证或手填隐藏 SSID。
5. 成功后显示 SSID、IPv4 地址和 RSSI；失败显示错误码与 Wi-Fi reason，可返回重输。应用最多做两次重试，连接/DHCP 每次有 25 秒期限，避免无限重试。

## 保存、断开与自动连接

- 只有成功收到 GOT_IP 后才保存新网络；错误密码或未拿到 IP 不覆盖旧网络。
- 只保存一组网络。`Connect saved` 使用已保存的网络。
- `Disconnect` 停止 Wi-Fi，保留已保存网络；退出页面不会断开已建立或正在尝试的连接。
- `Forget saved` 需二次确认，断开并删除该配置，不触碰好友、消息、昵称等其他 NVS 命名空间。
- 自动连接默认关闭；成功保存后可切换 `Auto reconnect: ON`，下次启动尝试连接。断开不会立即再次自动连接；自动连接指下次开机，以及当前会话掉线时的有限重试，不是永久循环。
- 密码保存在独立 `wifi_user/profile` NVS blob。当前固件没有启用 Flash/NVS 加密，**本地保存不等于加密保险箱**；不要把敏感密码用于不可信硬件。密码不进入状态快照或应用日志。

## 与蓝牙的关系

扫描器和连接页共用同一个 Wi-Fi 管理任务，避免重复初始化驱动。未联网的扫描临时暂停电台，完成后恢复；已连接时扫描用共存机制，不主动断开连接。Wi-Fi 在线和 BLE 可同时运行，但无线竞争可能降低消息或游戏响应，需要在具体网络环境验收。遥控器进入时等待正在进行的扫描结束。

离开 Wi-Fi 页面会释放只用于扫描的驱动；已连接/正在连接的 Wi-Fi 保留。断开后释放驱动和 netif，初始化过的全局 TCP/IP 任务保留。当前只用 IPv4 和 DHCP 客户端，关闭无用途的 IPv6、SoftAP、DHCP 服务器以节省固定固件分区。

## 验证

- `tools/test_wifi_credentials.c`：版本、SSID/密码长度、64 位十六进制 PSK、开放热点和自动连接字段校验。
- `python tools/test_wifi_state.py`：生产配置/事件处理逻辑，模拟 GOT_IP 才保存、重复 IP 不反复写、错误密码保留旧配置、过期事件隔离、重试上限、写入失败和独立删除。模拟驱动/NVS 不是实际入网验收。
- ESP-IDF 5.5.4 构建后运行 `python tools/verify.py`；真实密码仅由用户在设备输入，不应放入脚本或终端日志。

最终实机验收应看到 Xiaomi_6C64 的有效 IPv4，随后测试断开、保存网络重连、忘记网络，以及 Wi-Fi 在线时的 BLE 通信。没有目标热点密码时不能宣称这些已通过。

## 2026-10-20 实机进度

COM9、COM10 已更新，写入哈希校验通过。COM9 扫描到用户指定的 Xiaomi_6C64（约 -22 至 -30 dBm），已打开其空白密码页，未代填密码或发送连接请求。COM10 实测 BLE 扫描/信号、PPT/媒体配对页、Wi-Fi 扫描/重扫、退出后 BLE 恢复正常，无崩溃或栈检查失败；仅扫描后的内存页显示约 FREE 163 KiB / MIN 114 KiB。这不是 Wi-Fi 在线共存验收。

当前应用镜像 1,211,792 字节，固定单槽剩余 33,392 字节（约 32.6 KiB）。分区、NVS v7 和 storage ABI 未更改。获取 IP、真实认证、保存/重连/忘记与 Wi-Fi 在线时蓝牙交互，等待用户直接在设备输入密码后继续验收。
