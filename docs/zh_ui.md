# 系统双语界面与玩法说明（当前源码）

当前 main 源码包含主菜单、设置、工具、趣玩列表和双语玩法说明，不做中文输入、中文消息或协议变化。已发布的 `releases/final-2026-10-23` 仍是此前的命名/三地图版，不覆盖冻结镜像；本轮重新构建输出到 build/release。

## 中英文怎么切换

进入“设置”，转到最后一项“中文界面”，短按切换。勾选为中文，取消为英文；英文时这一项叫 `Chinese UI`，短按即可切回中文。立即生效，无需重启，并保存到独立的 `ui_locale/language_v1`。首次没有该记录时默认中文。

保存失败会显示“语言保存失败 / Language SAVE ERROR”，保留之前的语言；异常或未知版本记录不静默覆盖。不会更改宠物、好友、游戏、网络或云端凭证，NVS v7/storage ABI 1 不变。恢复出厂仍会清除全部用户 NVS，不能拿来当普通切语言手段。

## 去哪里看玩法

- “趣玩 > 玩法说明”（英文 `FUN > How to play`）可查看方块、蛇、答案之书、普通骰子、花旗骰、石头剪刀布、寻宝、反应赛、数字炸弹、盲猜秒数十项说明。每项四页，转动翻页，短按/返回回说明列表。不会开始游戏、扣体力或发奖励。
- “趣玩 > 电子宠物 > HOW TO” 查看七个宠物游戏、拜访、对战。中文说明每项四页，对战五页；英文保留原来两页/对战三页。自动说明仍须翻完当前语言的全部页面、总停留至少两秒，才算完整阅读一次；三次后跳过，手册回看不增加计数。计数跨语言共用，不重复引导。
- 中文每页两行，英文按原排版。小字页脚保留按键缩写：TURN=转动翻页，SP=短按，BACK=返回，START=开始。说明不翻译实际玩家昵称或消息内容。

## 范围与排版

- 主菜单八张磁贴：消息、摩斯电台、学习、好友、趣玩、设置、关于、工具，以及描述文字。标题和描述保持原滚动/裁剪逻辑。
- 设置十项（原九项后追加语言开关）、数值弹窗标题、恢复出厂确认文字、关屏/睡眠菜单。原数值与复选框索引不改。趣玩原十一项后追加说明入口，共十二项，其中说明不算一款新游戏。
- 工具八个入口、网络管理列表、遥控常用说明、云同步操作及常见状态。
- 32 像素高度不足以放三行 12 像素汉字，工具详情采用两行：保留顶部标题，底部详情/操作帮助每 3 秒交替；有控制输入先显示详情，短时提示优先。纯技术三行页保持原布局。
- SSID、设备名称、IP、MAC、RSSI、错误码、遥控键名以及用户文本不翻译。Wi-Fi 密码编辑器保持英文和掩码。游戏计分板、宠物内部的紧凑数值面板和摩斯教学并非全部汉化；消息短语映射后续再做。

## 实现与字库

`firmware/ui/ui_zh.c` 为精确匹配的英文键—中文表；`ui_zh.h` 提供绘制与字宽接口。系统绘制限定页面范围，不对消息弹窗、收件箱或编辑器做泛用替换。字体只在绘制中文时临时切换，随后恢复原字体。

`ui_language.c` 独立负责语言持久化，先成功提交再切换内存状态；`help_text.c` 分开维护中英文说明，不将英文字符串硬挤进中文布局。页面 ID 只追加 `M_GAME_HELP`（63），原页面与旧存档兼容。

字形源自仓库已有 `components/u8g2/csrc/u8g2_fonts.c` 的 `u8g2_font_wqy12_t_gb2312`，仅复制当前译文需要的字形与原 Latin 部分，不打包 20 万字节的完整 GB2312 字库。字形载荷不修改，可由 `tools/generate_zh_font.py` 重现。新增译文缺字或产物过期会在生成/测试时失败。

## 当前双语说明版构建

ESP-IDF 5.5.4，应用 1,555,056 字节，2 MiB 槽剩 542,096 字节（约 529.4 KiB）。比首轮固定中文增加 15,056 字节（约 14.7 KiB）。129 个显示键，454 个非 Latin 字形；精简字体数组 13,734 字节。SHA-256 `40679800c09e33d6233a6ec1e37becc65c5ecffb1b281fc36528481f7a1d8655`。源码与镜像清单核验通过。

宿主测试覆盖：语言默认值、无变化不重复写入、两个方向切换后重启、提交失败保留原语言、坏记录/未知版本不覆盖；所有中英文说明页面的实际字体宽度和绘制边界；中文必须看完四页才算完整阅读，三次后跳过，手动回看不重复计数。模拟 NVS 写失败不是实机拔电测试。

COM9 当前镜像已完成应用更新和回读，刷前两处 NVS、分区表保持不变。通过正常设置界面切为英文，逐页打开十项游戏说明及九项宠物说明；硬复位后英文开关行与复位前逐像素一致。随后切回中文，逐页检查相同项目；再次硬复位确认中文开关行逐像素一致，最终回到首页并保留中文。人工查看代表页面确认中文两行与小字页脚无重叠。证据在 build/language-help-smoke/COM9，未启动游戏、未注入比分或宠物数据；宠物仍正常后台成长。原有蛇/方块页面宿主回归通过，这不是全部联机或物理断电实测。
