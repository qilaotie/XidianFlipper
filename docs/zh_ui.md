# 系统双语界面与玩法说明（当前源码）

当前源码进一步补齐消息、频道、学习、好友、宠物及游戏子菜单的汉化，并在统一玩法说明里增加宠物分类。不做中文输入、中文消息或协议变化。已发布的旧冻结镜像不覆盖，新构建输出到 build/release；本次提交内容见[当前源码说明](current-source.md)。

## 中英文怎么切换

进入“设置”，找到“中文界面”（位于皮肤和首页选择之前），短按切换。勾选为中文，取消为英文；英文时这一项叫 `Chinese UI`，短按即可切回中文。立即生效，无需重启，并保存到独立的 `ui_locale/language_v1`。首次没有该记录时默认中文。

保存失败会显示“语言保存失败 / Language SAVE ERROR”，保留之前的语言；异常或未知版本记录不静默覆盖。不会更改宠物、好友、游戏、网络或云端凭证，NVS v7/storage ABI 1 不变。恢复出厂仍会清除全部用户 NVS，不能拿来当普通切语言手段。

## 去哪里看玩法

- “趣玩 > 玩法说明”（英文 `FUN > How to play`）可查看方块、蛇、答案之书、普通骰子、花旗骰、石头剪刀布、寻宝、反应赛、数字炸弹、盲猜秒数十项说明。每项四页，转动翻页，短按/返回回说明列表。不会开始游戏、扣体力或发奖励。
- 同一列表现在还有“电子宠物”，进入后有十三个主题：照顾与操作、成长与起名、商店与奖励、房间与待机动作，以及七个小游戏、联机拜访、联机对战。阅读时转动翻页，短按或返回回到宠物主题列表，再按返回回总目录。英文三行旧说明在此重排成两行多页，保留全部内容。
- “趣玩 > 电子宠物 > HOW TO” 查看七个宠物游戏、拜访、对战。中文说明每项四页，对战五页；英文保留原来两页/对战三页。自动说明仍须翻完当前语言的全部页面、总停留至少两秒，才算完整阅读一次；三次后跳过，手册回看不增加计数。计数跨语言共用，不重复引导。
- 中文每页两行，英文按原排版。小字页脚保留按键缩写：TURN=转动翻页，SP=短按，BACK=返回，START=开始。说明不翻译实际玩家昵称或消息内容。

## 范围与排版

- 主菜单八张磁贴：消息、摩斯电台、学习、好友、趣玩、工具、设置、关于，以及描述文字。标题和描述保持原滚动/裁剪逻辑，经典工具图标为独立工具箱。
- 设置十二项（包括语言、皮肤、首页选择）、数值弹窗标题、恢复出厂确认文字、关屏/睡眠菜单。原数值与复选框索引不改。趣玩共十二项，其中说明不算一款新游戏。
- 工具八个入口、网络管理列表、遥控常用说明、云同步操作及常见状态。
- 32 像素高度不足以放三行 12 像素汉字，工具详情采用两行：保留顶部标题，底部详情/操作帮助每 3 秒交替；有控制输入先显示详情，短时提示优先。纯技术三行页保持原布局。
- 消息、频道、好友与学习入口及常用状态已补齐；宠物主页、商店、背包、图鉴、成长、联机、房间、换蛋确认及小游戏操作提示采用中文双行。宠物名字原样显示，次要状态可轮换，选中的操作保持可见。中文换蛋确认仍需再次选择确认，不会因翻译直接执行。
- 方块暂停菜单在竖持方向显示中文，蛇的地图和暂停提示、花旗骰和答案之书、石头剪刀布及多人房间的操作提示也接入汉化；游戏数字、单位及紧凑技术缩写可保留 ASCII。
- SSID、设备名称、IP、MAC、RSSI、错误码、遥控键名、输入字符和用户文本不翻译。密码与名字编辑器保持原字符选择，不自动替换用户消息或快捷短语。摩斯字母、点划、WPM 和成绩数字保留原形式。

## 实现与字库

`firmware/ui/ui_zh.c` 为精确匹配的英文键—中文表；`ui_zh.h` 提供绘制与字宽接口。系统绘制限定页面范围，不对消息弹窗、收件箱或编辑器做泛用替换。字体只在绘制中文时临时切换，随后恢复原字体。

`ui_language.c` 独立负责语言持久化，先成功提交再切换内存状态；`help_text.c` 分开维护中英文说明，不将英文字符串硬挤进中文布局。页面 ID 只追加 `M_GAME_HELP`（63），原页面与旧存档兼容。

字形源自仓库已有 `components/u8g2/csrc/u8g2_fonts.c` 的 `u8g2_font_wqy12_t_gb2312`，仅复制当前译文需要的字形与原 Latin 部分，不打包 20 万字节的完整 GB2312 字库。字形载荷不修改，可由 `tools/generate_zh_font.py` 重现。新增译文缺字或产物过期会在生成/测试时失败。

## 历史：子菜单与宠物统一说明首轮构建

ESP-IDF 5.5.4，应用 1,580,736 字节，2 MiB 应用槽剩 516,416 字节（约 504.3 KiB）。511 个精确翻译键，632 个非 Latin 字形，字体数组 18,640 字节。应用 SHA-256：`ce979669a10eecb7bb469881d0f549c0a4b5fad83a25f10ac4087b6dde66ba9e`。相对上轮个性化版多 20,768 字节。

生产逻辑宿主测试覆盖十三个宠物主题的所有中英文页面、翻页环绕、逐级返回、旧英文三行重排无丢行、全部译文字形及宽度、竖持中文绘制边界、宠物菜单和小游戏提示。统一说明模块不链接宠物服务，不会扣币或启动游戏；既有宠物自动引导计数和存档格式不改。RPS、寻宝与四人游戏的状态机模拟回归通过，不代表多设备射频重验。

COM9 本轮已核查消息 / 频道 / 好友 / 学习菜单、十三个宠物主题首尾页，以及宠物商店 / 背包 / 图鉴 / 成长 / 联机 / 说明 / 房间。最终镜像补查蛇、方块暂停菜单、石头剪刀布和三个多人大厅；蛇的半屏提示缩短到可完整显示。退出方块必须使用暂停菜单里的“退出”，不能把 BACK 当作全局退出。没有确认购买、换蛋或发送消息，也没有新开游戏；不将界面检查当作完整玩法验收。最终返回首页，无看门狗重启或断言失败，证据在忽略的 `build/submenus-zh-smoke/COM9`。烧录前后分区表和两处 NVS 回读保持不变。

上述构建为本轮修复前的验证记录。随后补充宠物目录切换修复与主菜单顺序调整，见[当前源码说明](current-source.md)与[目录修复记录](help-transition-fix.md)。历史构建记录不能与当前镜像混用。
