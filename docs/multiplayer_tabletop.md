# 多人桌游使用手册

入口：**趣玩 → 多人桌游**。当前包含 10 款小屏适配游戏。井字棋改为完整棋盘直接操作，黑白棋因 8×8 棋盘无法清楚同屏呈现而先撤下，旧版黑白棋房间也不会接入。使用本机 C 规则和现有 BLE 自组网通信，设备之间直接玩，不连接 HullQin 网站的房间服务器。

## 开局与操作

1. 所有设备使用相同消息频道。如果启用了队伍/房间，还要加入相同队伍；公共频道和不同队伍互相隔离。
2. 每台设备进入多人桌游，将第一项“自组网”打开。该开关不会在重启后自动开启。
3. 一台设备选游戏，选择“创建并担任主机”；其他设备选择同款游戏，点“加入当前同款游戏”。同一范围可由不同设备同时主持多桌；加入时选择游戏桌并在详情中确认，每机只参与一桌，见[多桌说明](multi_table.md)。
4. 玩家到齐后，主机在房间的第三项开始。人数不满足规则时拒绝开局，不能用三台设备冒充五人阿瓦隆或狼人杀。
5. 井字棋开局后两台自动进入完整棋盘，其他游戏使用房间菜单。座位按 P1、P2……表示，名字显示设备名的前六个可打印字符；P1 是主机。

“我的手牌与身份”需**长按显示**，建议遮挡屏幕。普通短按不会揭示。UNO、情书的手牌可短按带入出牌表单；骗子酒馆短按手牌是勾选，最多同时出三张。

除井字棋直接在棋盘落子外，其他游戏在“执行操作”中：

- 短按首行切换动作，例如打牌、摸牌或质疑。
- 短按参数行进入编辑，旋钮修改，再短按结束编辑。`>` 表示正在修改该参数；不适用的参数显示 `--`。
- 短按“确认执行操作”才提交。收到主机确认并同步后再继续；被拒时检查轮次、目标、保护状态和参数。
- 参数编辑中按返回只是结束参数编辑，不提交；再次返回退出表单。

**返回上级或回首页仍保留游戏座位。** 明确选择“离开或结束本局”并确认，会结束整局，避免留下无人操作的座位。掉线设备使用原设备身份可恢复原座位；主持设备必须保持运行，主机重启不会恢复本局。游戏是 RAM 状态，不改写宠物、消息、好友、草稿或 NVS 版本。

每款“规则与操作”都有共用操作说明和六组专属规则，旋钮翻页，短按返回；中英长句按实际字体宽度换行分页。统一“玩法说明”也增加了多人桌游入口介绍。

## 游戏规则与参数

| 游戏 | 人数 | 主要操作 |
|---|---:|---|
| UNO | 2–8 | A 选手牌，B 为万能牌指定 A/B/C/D 花色；可摸牌、摸后结束、喊单牌、举报漏喊 |
| 谁是卧底 | 3–8 | 私下看词，线下描述；主机开启投票，每位活人选 A 目标投票 |
| 达芬奇密码 | 2–4 | A 对手、B 从左数牌位、C 数字 0–11；猜对可继续或收手 |
| 骗子酒馆 | 2–4 | 在手牌页勾选 1–3 张再出牌；下家接牌、质疑，或认可空手获胜 |
| 情书 | 2–4 | A 出哪张牌，B 目标，卫兵使用 C 猜 2–8 |
| 快艇骰子 | 2–8 | 掷骰、选择要保留的骰子、选择空的计分项目 |
| 阿瓦隆 | 5–8 | 队长勾选队员并提交；全员赞成/反对，队员提交任务成功/失败 |
| 一夜狼 | 3–8 | 按夜间阶段查看或交换角色，讨论后主机开最终投票 |
| 狼人杀 | 5–8 | 狼人选袭击目标，预言家查阵营，女巫用药；白天讨论与投票 |
| 井字棋 | 2 | 开局自动显示完整九宫格，旋转选空格，短按直接落子 |

### UNO

使用 108 张牌，初始每人七张。单色屏用 **A/B/C/D 四种花色**，出同花色或同点数。支持跳过、反转、罚摸两张、万能与万能加四；万能加四在手上没有当前花色时才能出。

摸一张后只可打出刚摸的牌，或结束本回合。罚摸不能叠加转移；这一版不包含“加四质疑”。剩一张后可声明单牌，别人举报漏喊会罚摸两张。先出完牌赢一局，不进行跨局积分赛。单手牌缓冲上限 32 张。

### 谁是卧底

内置 24 对中英文对应词语，随机一名卧底，其余平民看另一相近词。设备只展示自己的词，不直接提示自己是否卧底。所有活人投票，不能投自己，最高票出局；平票重新讨论和投票。找出卧底平民胜，卧底存活到只剩两人则卧底胜。

### 达芬奇密码

黑白两色各有 0–11。每人起始四张，按数字和颜色顺序排列；每轮新牌暂由当前玩家持有。猜对会公开对手对应位置，可继续猜或选择收手，将新牌暗置插入自己手牌。猜错将新牌明置插入，牌堆空时则公开自己一张未公开牌。插牌会改变位置，操作前重新看公共桌面。全部牌公开者出局，最后一人获胜。

### 骗子酒馆

每人三点生命、每轮五张牌，牌为三种点数及鬼牌。每轮指定一种声明点数，打出的 1–3 张都声称符合该点数，鬼牌可代替。下一家可继续出牌或质疑上一手；确实撒谎则出牌者扣一点，否则质疑者扣一点。质疑后重新发牌，零生命出局。出完牌仍需要下家认可或接受质疑；认可则该玩家胜。采用生命值反馈，不包含危险行为模拟。

### 情书

采用 16 张经典基础牌，烧一张；两人局额外移出三张。每回合两张手牌选一张打出。卫兵猜中淘汰、牧师查看、男爵比点、侍女保护、王子弃牌重摸、国王换牌、伯爵夫人遇王子/国王必出、公主被弃则自己出局。其他人均受保护时，无可选目标的效果落空；保护与目标合法性由主机判断。

存活只剩一人获胜；牌堆耗尽比较剩牌点数，平手再比较本局弃牌点数和。只结算单局，不包含跨局好感标记赛。

### 快艇骰子

五颗骰子，每回合最多三掷，可逐颗保留。十三个项目各填一次：上区一至六点、三同、四同、葫芦、小顺、大顺、五同、全选。上区满 63 额外加 35；葫芦 25、小顺 30、大顺 40、五同 50；三同/四同达标取骰子总和，全选直接取总和。允许主动填零分，所有人完成十三轮后比总分。

### 阿瓦隆

基础阵容包括忠臣、梅林、刺客、爪牙。五六人局两名坏人，七八人局三名；梅林和坏人可在自己的身份页查看所知坏人座位。任务人数按标准五轮表变化：

| 人数 | 五轮任务人数 |
|---:|---|
| 5 | 2、3、2、3、3 |
| 6 | 2、3、4、3、4 |
| 7 | 2、3、3、4、4 |
| 8 | 3、4、4、5、5 |

组队表决须超过半数赞成；连续五次否决则坏人胜。任务队员各提交一张成功或失败，好人不能提交失败。七八人局第四轮需要两张失败，其余一张即失败。三次任务失败坏人胜；三次成功后刺客指认梅林，指中仍由坏人胜。此版没有额外扩展角色。

### 一夜狼

有三张中心牌，基础角色为狼人、预言家、强盗、捣蛋鬼、村民。按狼人、预言家、强盗、捣蛋鬼顺序行动，非当前角色等待；角色也可主动放弃行动。

- 狼人能查看同伴；仅一名玩家是狼人时可看一张中心牌。
- 预言家 A 选择一名玩家，或选择三张中心牌之一；选择中心时，B 再指定另一张中心牌。
- 强盗 A 选择另一玩家，与自己交换并查看换得身份。
- 捣蛋鬼 A/B 选择另外两人，交换其身份，自己不能参与。

行动后自由讨论，主机开启一次最终投票。允许投自己，最高票若达到两票则被淘汰；并列最高均淘汰。按交换后的最终身份结算，杀死至少一名狼人则好人胜；没有玩家是狼人时，没人被淘汰才是好人胜。不包含其他扩展角色。

身份页首项是自己的初始身份。强盗另能看到换得身份；其他交换后的最终身份在结算时公开，讨论阶段不会提前告知。

### 狼人杀

五人局一狼，六人及以上两狼；有预言家、女巫，七人及以上加入猎人，其余村民。夜间狼人可各自选目标，按最高票袭击，同票按座位顺序；预言家看阵营；女巫知道当夜被袭击者。女巫 A=0 跳过、1 解药、2 毒药，B 为毒药目标，每种药全局只能用一次，每晚最多用一种。猎人被毒不能开枪，其他死亡可以开枪或放弃。

白天线下讨论，主机开启投票；最高票唯一者出局，平票无人出局进入下一夜。狼人全灭好人胜，存活狼数不少于好人数则狼人胜。没有警长、遗言计时、屠边与扩展身份。

### 井字棋

叉先圈后，横竖斜三连胜，满盘无连线和棋。完整 3×3 格线固定显示在屏幕左侧，棋子用图形 X/O，亮格是当前选择；右侧显示自己的棋子、坐标及回合/结果。

旋转跳过已有棋子，只选空格；轮到自己时短按直接落子。等待对方、同步中或游戏结束时短按不会再下棋。开局自动进棋盘，按 BACK 可回房间看说明、名单或结束本局，“棋盘对战”可重新打开，不会反复强制跳回棋盘。没有电脑对手，需要两台设备。黑白棋暂不可创建、加入或开始，保留旧编号避免改变其他游戏的联机编号。

## 同步与数据边界

规则仅由主机执行。客户端操作含会话、局号、版本与操作序号，等待明确确认；重复请求不会重复应用。同阶段各自投票允许并发，出牌等有序操作要求当前版本，过期请求拒绝。公共状态和面向各座位的手牌/角色分别同步，客户端只有版本配套时才允许操作。

使用既有 COLLAB 类型 20–24 号子操作，并沿用队伍范围封装，未变更持久消息和存档格式。BLE 内容仍为现有明文实验通信：屏幕遮挡和座位过滤面向朋友聚会，不构成加密防作弊机制。当前没有主机迁移、断电存档或网站跨端互通。

宿主测试、射频测试和实际人数应分别记录。三台设备不能证明五至八人实机完整对局通过；最新构建和设备验收见 [桌游验证记录](tabletop_validation.md)。
