本轮本地更新：中文模式下，宠物各子菜单和小游戏提示使用中文双行；改名时仍输入原英文字符。统一入口“趣玩 → 玩法说明 → 电子宠物”新增十三个主题，涵盖照顾、成长、商店奖励、房间及全部小游戏和联机规则。仅阅读不会开始游戏、扣体力、购买道具或改变自动说明计数。原宠物内部“说明 / HOW TO”仍保留。

本地追加：宠物主页新增 `ROOM`，提供原房间、25G 书房、35G 花园、50G 太空。旋转免费预览，短按购买并装备；买过后重复切换免费，兼容原有盆栽 / 星饰 / 地毯。新增打哈欠、挠头、小跳、跳舞、玩球等待机动作。完整操作和存档降级限制见[个性化说明](personalization.md)。

整理日期：2026-10-23。适用于当前 V1.0 功能扩展版（用户命名、七个单人小游戏与 Connection 风格联机）。

2026-10-23 本地追加用户命名：首次进入尚未命名的宠物，会打开 PET NAME。最多 12 个可打印英文、数字、空格或符号，不支持中文，不能为空或全空格。转动选 ABC / abc / 123 / SYM 分组，短按进入字符组，转动选字、短按添加；BACK 先退回分组，在分组层再 BACK 取消。SPACE 加空格、DELETE 删最后一字，SAVE 保存，也可长按直接保存。达到上限或写入失败会提示，保存失败不改旧名字。

以后在宠物主菜单选择 NAME 改名。昵称独立保存到本机，关机保留，不清空年龄、金币、图鉴或成长数据；重新养蛋沿用昵称。首页第一行显示昵称，形态仍在图鉴和成长页查看。联机发送昵称前 7 个字符（现有包长限制），未命名时退回设备昵称。云端现有展示/排行榜仍使用设备昵称，这次不改网页或云端数据协议。

COM9 实机已通过正常输入界面设为用户指定的 `pet`，硬复位后首页昵称行与复位前一致。生产存储宿主测试另覆盖空名/全空格/超长拒绝、12 字符上限、提交失败不替换旧名、未知版本保护；联机昵称发送已做宿主包检查，本次未用第二台设备验证射频显示。

设备内有简略玩法页：每个 PLAY / CONNECT 项目初次使用自动显示，完整看过三次后该项目不再自动弹出，直接开局/搜索。每次须翻到全部页面、总停留至少两秒，离开才算一次；快速略过不计数，项目之间独立计数，重启和重新养蛋都保留。

随时可去 `Pet > HOW TO` 选择项目回看。自动说明转动翻页、短按 START 开始、BACK 回列表；HOW TO 内是只读说明，短按或 BACK 都回说明列表，不会误开游戏。看说明不扣游戏精力或饱食。宠物七游戏、拜访各两页，对战三页；使用现有英文字库，LEFT=逆时针、RIGHT=顺时针、TAP/SP=短按。

说明页包含操作、获胜门槛和关键时限，例如举旗双旗要短按、顶球在最后 300 毫秒按、记忆须等 YOUR TURN 再输入。已知玩法时可以在第一页直接短按开局，不必每次翻完；这样不计入完整阅读次数。体力不足不会开局，阅读期间正常后台成长与属性变化仍会继续。

这是一只住在设备里的电子宠物：可以照顾、养成不同形态、玩游戏赚金币、购买道具和装饰，也可以拜访附近设备里的宠物、进行双人对战。不设死亡，不需要手机或网络账号。

本功能是适合本机小屏和旋钮的原创轻量实现，不是正版拓麻歌子固件，也不能与正版玩具互联。当前没有疾病治疗、婚育、赠礼或永久好友亲密度系统。

## 1. 第一次玩：三分钟上手

1. 首页短按旋钮进入菜单，选择 `FUN > Pet`。
2. 如果还是 EGG（蛋），保持设备开机，累计约一分钟后孵化。已有宠物直接继续照顾，不需要重新养蛋。
3. 在宠物主界面长按旋钮，查看 FOOD、MOOD、REST、WASH 四项数值；再次长按恢复普通显示。
4. 选择 FEED 喂食、CLEAN 清洁。连续照顾时，两次成功操作之间留约两秒。
5. 有足够精力时进入 PLAY，选一个小游戏，先看玩法页，再短按开局。新手推荐 SPRINT（赛跑），20 秒内短按至少 30 次即可获胜。
6. 获胜可得 8G。到 SHOP 购买商品，再到 BAG 使用或装备。
7. 玩累了选 SLEEP，让宠物睡觉恢复精力；准备玩游戏时，再选 WAKE 唤醒。
8. 离开时用 BACK 逐级返回，并等待 SAVING 提示消失后再断电。

第一次创建宠物存档有 30G、一枚 APPLE 和一块 SOAP；已经有存档不会重复发放。基础喂食、清洁、睡觉都免费，不必先买道具。

## 2. 按键和菜单

### 基本操作

| 操作 | 用途 |
| --- | --- |
| 转动旋钮 | 选择菜单或物品；游戏中按规则控制方向 |
| 短按旋钮（SP / TAP） | 确认、执行动作或游戏操作 |
| 长按旋钮 | 宠物主界面切换详细属性；命名界面保存昵称 |
| 独立返回键（BACK） | 返回、取消或退出；未完成的游戏视为放弃 |

小游戏中的 LEFT 是逆时针转动一格，RIGHT 是顺时针转动一格，TAP 是短按。不要把转动一格和长按混用。

### 宠物主界面选项

| 屏幕名称 | 中文含义 | 功能 |
| --- | --- | --- |
| FEED | 喂食 | 免费增加饱食和心情 |
| PLAY | 玩游戏 | 六个新小游戏和 QUICK TAP 列表 |
| CLEAN | 清洁 | 免费恢复清洁度 |
| SLEEP / WAKE | 睡觉 / 唤醒 | 切换宠物睡眠状态 |
| SHOP | 商店 | 花金币购买道具、玩具、装饰 |
| BAG | 背包 | 使用道具、玩玩具、装备或取消装饰 |
| DEX | 图鉴 | 查看见过的形态，或进入重新养蛋确认 |
| GROWTH | 成长 | 查看年龄、良好照顾进度、训练胜利进度和成年形态 |
| CALLS ON / OFF | 提醒开关 | 开启或关闭宠物需求提醒 |
| CONNECT | 联机 | VISIT 拜访、DUEL 双人对战 |
| HOW TO | 玩法说明 | 随时回看七游戏、拜访和对战说明，只读不启动 |

选项后面的 G 是钱包金币，例如 `>FEED 30G` 表示当前有 30G，不是喂食要花 30G。

返回层级：小游戏 BACK 回游戏列表，再 BACK 回宠物主界面；联机 BACK 回 CONNECT 列表，再 BACK 回宠物主界面。在宠物主界面再次 BACK 才退出宠物功能。

## 3. 日常照顾与属性

四项属性范围都是 0–100，达到上限后不再增加，降至零不会死亡。

| 显示 | 含义 | 建议做法 |
| --- | --- | --- |
| FOOD | 饱食 | FEED 免费喂食，或在 BAG 吃苹果/零食 |
| MOOD | 心情 | 玩游戏、喂食、清洁、吃零食或玩 BALL |
| REST | 精力 | SLEEP 睡觉恢复；WAKE 唤醒 |
| WASH | 清洁 | CLEAN 免费清洁，或使用 SOAP |

### 免费照顾效果

- FEED：饱食 +20、心情 +3。
- CLEAN：清洁恢复到 100、心情 +3。
- SLEEP：进入睡眠；醒来需要手动选 WAKE，不会因为精力满自动醒来。
- 宠物游戏的一次体力消耗：精力 -8、饱食 -3、心情 +15。六个新游戏在开局消耗，QUICK TAP 在完成一局时消耗；联机对战在确认开局过程中消耗。

### 每分钟的自然变化

| 状态 | 饱食 | 心情 | 精力 | 清洁 |
| --- | ---: | ---: | ---: | ---: |
| 醒着 | -2 | -1 | -2 | -1 |
| 睡觉 | -1 | -1 | +8 | -1 |

数值在宠物年龄跨过完整分钟时结算，不是每秒平滑变化。饱食低于 20 或清洁低于 20 时，该分钟的心情还会额外 -1。

精力为零时先喂食、清洁，再让它睡觉。大约每分钟恢复 8 点精力；恢复一点后就唤醒连续玩，很快又会疲倦，建议多休息几分钟。

睡着时不能喂食、清洁、玩宠物游戏或使用食物/清洁道具。先 WAKE，等约两秒，再执行下一项。睡着仍可以买商品、装备装饰和拜访。

## 4. 成长、进化和自主动作

### 成长阶段

| 累计宠物年龄 | 阶段 |
| --- | --- |
| 0–59 秒 | EGG：蛋 |
| 1–9 分钟 | BABY：幼体 |
| 10–29 分钟 | TEEN：少年 |
| 30 分钟起 | 成年，确定进化分支 |

这里是设备正常运行时累计的时间，不是真实日历年龄。去其他菜单或只是关屏，宠物仍会成长、变化；设备断电或进入深睡期间不推进，也不补算离线时间。

宠物自己的 SLEEP 与设备深睡不同：只要设备仍正常运行，宠物睡觉也会成长、恢复精力。

### 三种成年形态

成年时按以下顺序判断一次，之后形态固定：

1. 当前宠物累计训练胜利至少 5 次 → SPORT，运动型，长耳。
2. 未满足上一条，但累计良好照顾至少 24 分钟 → SUNNY，阳光型，尖耳。
3. 其余 → MELLOW，悠闲型，圆头小呆毛。

“良好照顾”是在每个完整分钟结算属性后，饱食 ≥40、心情 ≥40、精力 ≥20、清洁 ≥40。满足就累计一分钟，不要求连续；只在成年形态确定前累计。

训练胜利来自宠物小游戏获胜、联机对战获胜，以及方块/贪吃蛇达到训练门槛。单独在 BAG 玩 BALL 不算获胜。

GROWTH 中 CARE 显示良好照顾进度，最多显示 24/24；WINS 显示训练胜利进度，最多显示 5/5，不是超过五局就不再记录。底部是预计或已经锁定的形态。已经成年再刷胜利不会改成 SPORT；要收集另一种形态，需要重新养蛋。

### 自主小动作

宠物平时会眨眼、张望、走动、跳跃、伸展、坐下和挥手；低精力时动作更安静，睡觉时有呼吸动作。这些是显示动画，不代表它会自动喂食或替你操作游戏。

## 5. 需求提醒和声音

已孵化且醒着时，任一属性低于 25，会请求照顾。多项同时不足时，优先顺序为饥饿 → 疲倦 → 清洁 → 陪伴。

| 首页提示 | 意思 | 处理 |
| --- | --- | --- |
| PET: HUNGRY | 饿了 | 喂食 |
| PET: TIRED | 累了 | 睡觉 |
| PET: NEED WASH | 需要清洁 | CLEAN 或 SOAP |
| PET: PLAY WITH ME | 需要陪伴 | 检查体力后玩游戏，或使用玩具/零食 |

提醒最多每三分钟触发一次，启动后前约十秒不触发。只在首页、主菜单、宠物非游戏/非联机页面安排提醒，不打断其他游戏、摩斯或遥控器，也不唤醒屏幕。文字横幅只显示在设备首页底部，约四秒后消失，不是所有页面都会显示横幅。

有声提醒需要同时满足：宠物 CALLS ON，以及 `SETTINGS > Buzzer Enable` 开启。系统静音时只保留首页文字提醒；CALLS OFF 则关闭宠物需求提醒。宠物睡觉、未孵化、存档报错或声效通道忙碌时，不会按通常方式立即叫你。

## 6. 七个宠物小游戏

入口：`FUN > Pet > PLAY`。需要已孵化、醒着，精力至少 8、饱食至少 3。刚照顾完无法开局时，等约两秒再试。

六个新游戏每局最长 20 秒，获胜得 8G、增加一次训练胜利。中途 BACK 不发金币，已经消耗的精力和饱食不返还。结果页短按或 BACK 返回游戏列表。

### GET NOTES：接音符

转动旋钮，在左、中、右三个位置移动篮子，落下时与音符同列即得一分，不需要短按。`YOU` 是自己的位置，`TARGET` 是音符位置，`LAND` 是剩余落下时间。10 个音符至少接住 6 个获胜。

### BUMP：相扑

观察 POWER 数值和左右移动的力量条，POWER 达到 7、8、9 或 10 时短按发力。每次有效发力后至少间隔约半秒才能再发力，没必要不停乱按。5 次发力至少成功 3 次获胜。

### FLAGS：举旗子

- LEFT / 左旗：逆时针转一格。
- RIGHT / 右旗：顺时针转一格。
- BOTH: TAP / 双旗：短按。

每题限时约 1.2 秒。答错或超时不加分，10 题至少答对 6 题获胜。连续题之间有约 250 毫秒输入保护，避免一次转动误答下一题。

### HEADING：顶皮球

转动到球所在列，等待剩余时间进入最后 300 毫秒，再短按顶球。太早短按不顶球，可以继续等待；错列或错过落地时机不加分。10 球至少顶住 6 球获胜。

### MEMORY：按键记忆

先看 REMEMBER 阶段依次出现的 LEFT、RIGHT、TAP；出现 YOUR TURN 后，用逆时针、顺时针、短按按原顺序重复。不要在展示阶段抢答。

序列从两步开始，完成后增加到三步、四步、五步；每个输入最多等待约五秒。答错或输入超时会结束。至少完整完成前三轮即可达到获胜门槛；游戏也受整局 20 秒限制。屏幕上的 STEP 是本轮步骤，不是总金币。

### SPRINT：赛跑

快速短按，不要长按不放。20 秒内至少完成 30 次有效短按获胜，达到 40 次可提前结束。间隔小于约 110 毫秒的输入不重复计数。

### QUICK TAP：快速反应

这是保留的原小游戏：随机等待约 2.2–4 秒，看到 GO! TAP 后，在 1.2 秒内短按。提前按或太迟按不发奖；GO 后超过约三秒未按会自动结束。

完成一局时消耗精力和饱食；获胜得 8G，并增加一次训练胜利。BACK 可取消尚未完成的这一局。结束后直接回宠物主界面，而不是六小游戏的结果页。

## 7. 金币的其他来源

| 玩法 | 金币 | 成长训练 |
| --- | --- | --- |
| Pet 内小游戏 | 每次获胜 8G | 每次胜利 +1 |
| Pet 联机 DUEL | 胜者 20G、平局各 10G、败方 6G | 仅胜者 +1 |
| FUN > Tetris | 每消一行 5G | 一局累计消 4 行时 +1，最多一次 |
| FUN > Snake | 每吃一个食物 2G | 一局累计吃 5 个食物时 +1，最多一次 |
| Pet 联机 VISIT | 每方 5G + 一件随机消耗品，每台每三分钟限一次 | 不增加 |
| BAG 玩 BALL、随机骰子等 | 不发金币 | 不增加 |

方块、贪吃蛇的奖励自动进入同一个宠物钱包，游戏内 G 显示本局实际收入。不需要先打开宠物页面；它们也不扣宠物游戏的 8 精力/3 饱食。

蛋或睡眠状态下玩方块/贪吃蛇仍能赚金币，但达到训练门槛的那一刻，宠物必须已孵化且醒着，才能增加训练胜利；之后唤醒不补记该局错过的训练。金币与训练是两回事。

钱包上限 9999G。重复刷新、暂停、移动、重开本身不发金币；满额时未入账的奖励不会在以后消费后补领。游戏显示的通关奖励是标称值，实际入账受钱包上限和存档状态限制。

## 8. 商店、背包和装饰

流程：`SHOP 购买 → BACK → BAG 使用或装备`。买了装饰不会自动显示，需要再到 BAG 装备。

| 名称 | 价格 | 类型 | 使用效果 |
| --- | ---: | --- | --- |
| APPLE 苹果 | 10G | 消耗品 | 饱食 +35、心情 +5 |
| SNACK 零食 | 8G | 消耗品 | 心情 +25、饱食 +5 |
| SOAP 肥皂 | 12G | 消耗品 | 清洁恢复 100、心情 +5 |
| BALL 小球 | 40G | 永久玩具 | 每次精力 -4、心情 +12；不发金币 |
| PLANT 盆栽 | 25G | 永久装饰 | 装备后显示盆栽 |
| STARS 星星 | 35G | 永久装饰 | 装备后显示星星 |
| RUG 地毯 | 20G | 永久装饰 | 装备后显示地毯 |

三种消耗品分别最多九个；永久物品只能买一次，可以反复使用或装备。金币不足、数量满或永久物品已拥有时，购买失败不扣金币。

使用消耗品会扣一件道具，不再扣金币。宠物没孵化、睡着、数量为零或对应属性已满时，可能不能使用。BALL 需要已拥有、醒着且精力至少 4；心情已满时不消耗精力。

一次只能装备一种装饰。选择另一种已拥有装饰即可更换，BAG 最后一项 NO DECOR 用来取消装饰，物品不会丢失。装饰只有显示效果，不会自动增加属性或金币。

## 9. 联机拜访和对战

准备两台支持本功能的同版设备，放在附近。通信走设备之间的 BLE，不要求 Wi-Fi、手机、相同短信频道或先加好友；不是通过互联网寻找玩家。

### VISIT：拜访

1. 两台分别进入 `FUN > Pet > CONNECT > VISIT`，在说明页短按 START，进入搜索。
2. 等约三秒发现对方。一台短按发出邀请，会选择当前信号最强的同模式设备。
3. 另一台看到邀请和对方昵称后，短按接受；BACK 可拒绝并返回。
4. 倒计时约三秒，两只宠物一起显示、做小动作，约八秒后结束。
5. 结束后显示 GIFT 商品名与实际金币，或 NO GIFT / LIMIT（奖励受限）。短按重新搜索，BACK 退出。

拜访不花金币、不消耗精力，蛋和睡着的宠物也允许。双方确认完成后，每台各获 5G 与一件随机 APPLE / SNACK / SOAP；这是系统礼物，不从对方背包扣除。选中的消耗品已经九个则不再加物品，只发可入账的金币。

每台设备每三分钟最多领取一次拜访奖励；更换对手或重启不能绕过。冷却按设备正常运行时间推进，断电/设备深睡不补算，重新养蛋不重置冷却。冷却期间仍可拜访，只是不发礼物。当前没有手动向对方转移背包物品或繁殖功能。

### DUEL：双人对战

双方都进入 `CONNECT > DUEL`，按照同样的“发现 → 邀请 → 对方确认”流程开局。两台都需要已孵化、醒着、精力至少 8、饱食至少 3，并避开照顾后的两秒操作间隔。

系统随机选择相扑、顶皮球或赛跑，不能在此菜单手动指定。双方共享本局设置，倒计时后按相应玩法操作，以最终得分高低判断胜负，不按单人通关门槛判断。联机顶球中的 Y 是自己位置、B 是球位置，毫秒数是剩余时间，SP:<300 表示最后约 300 毫秒短按。

双方确认开局过程中各扣一次游戏体力。WIN 胜者得 20G 和一次训练胜利；DRAW 平局双方各 10G；LOSE 败方得 6G，不增加训练胜利。完成后先等双方结果确认；WAIT PEER RESULT 表示对方仍在玩或正在等待确认，不能立即当作卡住。结果页显示实际到账金币，钱包上限仍为 9999G。

结果页短按重新搜索下一局，BACK 返回 CONNECT。已消耗的体力不因中途退出或掉线返还；未确认的对局不发奖励。它是娱乐对战，不保证毫秒级计时公平，也不是防作弊竞技系统。

### 常见联机提示

| 提示 | 含义与处理 |
| --- | --- |
| BOTH OPEN; SP: INVITE | 双方都需打开同模式；稍等发现后，一台短按邀请 |
| WAIT PEER ACCEPT | 等另一台短按确认 |
| SP: ACCEPT BACK: NO | 有邀请；短按接受，BACK 拒绝 |
| START IN | 开局倒计时 |
| WAIT PEER RESULT | 不要退出，等对方完成并确认结果 |
| LEFT/NOT READY SP:RETRY | 对方退出、未准备好或超时；检查状态后短按重试 |
| RADIO NOT READY | 无线尚未准备好，等待或退出后重新进入 |

连续约 15 秒没收到对端消息会超时。多台同时在场时，信号最强不一定是你想找的那台，建议演示时只让目标两台打开同模式。昵称最多显示前七个 ASCII 字符，中文等当前字库不能正常显示的字节会替换为问号，建议使用简短英文/数字昵称。

## 10. 图鉴和重新养蛋

DEX 共六项：EGG、BABY、TEEN、SUNNY、SPORT、MELLOW。见过的形态显示 DISCOVERED 和预览，未见过的显示 LOCKED / 问号。图鉴预览不是改变当前宠物，也不能直接领取未解锁形态。

收集其他成年形态，可以从 DEX 最后一项 NEW EGG? 进入确认页。默认 KEEP PET（保留当前宠物）；必须转到 NEW EGG 并短按，才会让当前宠物退休，从蛋开始。BACK 可取消。

重新养蛋保留：金币、背包、永久物品、当前装饰、累计图鉴、CALLS 提醒偏好、各项目说明阅读次数、拜访奖励冷却。重置：当前宠物年龄、四项属性、睡眠、照顾记录、训练胜利和成年形态；不会再赠送 30G、苹果或肥皂。确认后不能从界面恢复上一只，展示时不要误确认。

## 11. 保存和升级注意事项

照顾、金币、背包、装饰、图鉴和提醒偏好会一起保存。普通操作通常合并约五秒写入，后台成长约每分钟保存；正常退出宠物页、退出方块/蛇、完成新小游戏或结算联机对战时会尝试立即保存。

- SAVING...：还有待保存的变更，等提示消失再断电。
- SAVE ERROR：存档读写异常；不要反复购买、清档或来回降级，应保留现场排查。
- 不要把“可以重启保留”理解成“任何时刻拔电都不丢最近动作”，尚未写入的操作可能丢失。
- 正常保留数据的固件更新不会主动重置宠物；全片擦除或擦掉 NVS 会破坏存档，不属于正常更新。
- 旧宠物会迁移保留年龄、属性和睡眠，不强制变成蛋；请避免来回刷不兼容的旧固件。
- 新增独立 `pet_user/extra_v1` 小记录保存说明计数、运行时间和拜访冷却，原宠物记录仍为 v2。拜访先保存冷却再发礼物，防止断电重复领；这两次写入之间突然断电可能丢失本次礼物，不能保证任意断电时刻都完整到账。未知或损坏的新增记录也会报 SAVE ERROR，不自动覆盖。
- 新联机载荷版本为 2，双方都需要本版，不能与此前载荷版本 1 的宠物联机。

这份手册按当前源码核实规则，历史实机记录见 [宠物 v2](pet_v2.md)、[生活与金币联动](pet_life_rewards.md)、[六小游戏与联机验收](pet_connection_games.md)。历史验收已覆盖 COM9/COM10 拜访、相扑对战、单人赛跑赚币和重启保留；联机顶球/赛跑尚未逐项实机验收。当前说明记忆与社交奖励版的新增验收记录也集中在联机说明中，不把宿主模拟测试当作实机验收。

## 12. 常见问题与演示建议

| 问题 | 优先检查 |
| --- | --- |
| 喂食或开局按了没反应 | 是否还是蛋、正在睡觉、刚操作不足两秒，或出现 SAVE ERROR |
| 游戏提示 WAIT / WAKE UP | 先唤醒，再查精力 ≥8、饱食 ≥3；精力不足必须睡觉恢复 |
| 睡着后不自动醒 | 正常，需要手动选 WAKE |
| 宠物很久不长大 | 断电/设备深睡不计时；普通关屏与宠物睡觉则继续计时 |
| 玩很多次却没变 SPORT | 要在成年定型之前累计训练胜利；成年后不再改形态 |
| WINS 到 5 就不涨 | 成长页只显示目标进度上限 5/5 |
| 买了盆栽看不到 | 去 BAG 选择 PLANT 再短按装备 |
| 没钱，是否不能照顾 | FEED、CLEAN、SLEEP 免费，先用基础照顾 |
| 方块或蛇赚币却没加 WINS | 未达到本局训练门槛，或门槛那一刻宠物是蛋/睡着；每局训练最多一次 |
| 显示胜利但金币没有增加 8 | 钱包可能接近 9999 上限，或存档异常；检查钱包与 SAVE ERROR |
| 没听见宠物叫 | CALLS ON、Buzzer Enable、宠物是否醒着、是否低于提醒阈值、是否仍在三分钟间隔内 |
| 联机找不到对方 | 两台是否同版、同模式、距离合适；等待发现后再邀请 |
| 联机显示代号/问号 | 检查昵称；本页只支持简短 ASCII 名称 |

### 适合现场展示的操作顺序

提前把两只宠物喂饱、清洁、睡觉恢复精力，并手动唤醒。正式展示时：

1. 长按看四项属性，做一次免费喂食，展示自主动作。
2. 打开 GROWTH，解释照顾和训练对进化的影响。
3. PLAY > SPRINT，获胜后看金币增加。
4. SHOP 买装饰，BAG 装备，展示场景变化。
5. 两台 CONNECT > VISIT，邀请、接受并展示双宠物。
6. 两台 CONNECT > DUEL，等双方结果，比较比分和钱包。
7. 看 DEX 已解锁形态，最后用 BACK 正常退出保存；不要为演示误确认 NEW EGG。

进化需要累计开机时间，不能在几秒演示内完成；最好提前养好不同阶段/形态的设备。小游戏与联机都会消耗精力，连续彩排前预留休息时间。
