# 俄罗斯方块与贪吃蛇存档

2026-10-23 本地新增版，入口仍为 FUN > Tetris portrait / Snake。存档功能最初在原分区加入；同日后续的[2 MiB 分区迁移](partition_migration.md)仅调整应用槽，NVS v7、storage ABI 1、宠物/好友/Wi-Fi 存档分区地址与大小保持不变。

## 最高纪录

- 贪吃蛇：保存最高食物分数/最长长度，长度 = 食物分数 + 初始三节。暂停时右下角 B 是最高食物分数。
- 方块：最高分和最多累计消行数分别保存，暂停时顶栏 BEST 显示最高分、L 显示最多消行数；不一定来自同一局。开始后顶栏恢复本局分数和行数。
- 新游戏和游戏结束不会清掉最高纪录。

## 继续上局

当前贪吃蛇支持 CLASSIC / PILLARS / GATES 三张地图，地图随当前局保存。旧存档默认经典地图；NEW GAME / 长按进入选图，短按确认才覆盖旧局，选图时 BACK 可以取消并退出。最高分和每食物 2G 仍共用，没有分地图榜单。

- 贪吃蛇：有未结束存档时，进入显示 CONTINUE / NEW GAME。转动选择，短按确认。选 CONTINUE 后仍暂停，再短按开始；长按也能明确新开一局。BACK 保存退出。
- 方块：有未结束存档时，暂停菜单第一项显示 CONT；选择它并短按继续。NEW 新开，EXIT 保存离开。游玩中 BACK 打开暂停菜单，再选 EXIT。
- 重进默认暂停，不会在你看菜单时自动死亡。蛇保存身体、方向、待执行转向和食物；方块保存棋盘、当前/下一个方块、七袋随机状态、位置和旋转。加载后消行动画直接视为已完成，不重复消行。
- 结束的棋局不会作为继续上局加载，只保留纪录；新开后不能从界面恢复此前的局。

## 保存时机

棋局有变化时约每 30 秒保存一次，正常退出、进入设备深睡前保存；得到食物/消行奖励前也会保存领取进度。不会每走一步都写 Flash。突然断电可能回退到最近的保存点。

游戏记录独立存于 arcade_user 命名空间，两个带版本/校验的记录，不含 Wi-Fi 密码。读到损坏或未知记录会提示 SAVE ERR / SAVEERR，不自动覆盖；明确长按 NEW 或选择 NEW 才会替换该记录。写入失败也显示错误，正常演示不应直接清空整片 NVS。

## 金币和训练防重复

沿用方块每行 5G、蛇每食物 2G；当前局的领取进度和训练门槛状态随档恢复。先保存领取进度，再发金币并提交宠物状态，避免退出、重启或反复读档重复领奖。

这不是跨命名空间的原子事务：恰好在进度保存与宠物入账之间断电，可能少记一次金币或训练，但不能通过读档补领同一段进度。背包、钱包上限和门槛当时醒着/已孵化等原规则不变。

## 构建与验证

本版应用 1,241,888 字节，单槽 1,245,184 字节，剩 3,296 字节（约 3.2 KiB），没有删除其他功能。应用 SHA-256：`e7594f9939ddef1d0177dbbaf714d3fb2118d32cf78854705aceb9aa566f2b33`。

宿主测试 tools/test_arcade_store.py 使用生产存储代码与模拟 NVS/宠物接口，覆盖恢复、最高纪录、奖励前写入、写失败、坏记录、消行动画归一和防重复计奖。蛇/方块 UI 另有 5000/20000 次渲染边界回归，生产宠物服务测试覆盖恢复奖励水位后不重复训练。这些不是拔电或 Flash 故障实测。
