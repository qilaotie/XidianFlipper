## 真实代存

A=COM10、B=COM15、C=COM9。真实 BLE 收发，USB只模拟正常输入/读取屏幕。离线设备停在下载模式，应用和射频不运行，没有注入协议或存档。

1. C 停止运行，A 发 `QM01`，B 主动开启代存。双读证明 A 为 WAIT，B 持久缓存原始源/目标/会话/消息 ID。
2. B 重启后手动开启，A 停止运行、C 恢复。B 独立转交，C 只保存一次；B 移除缓存并保存 C 的真实回执身份。
3. C 再停止运行，A 恢复，以原身份重试。B 重放保存的真实回执，A 变为 DELIVERED。排除了 C 此时直接回应的解释。
4. 只清理 A 的测试草稿/发件箱槽，保留新测试收件和回执标记，不删除旧消息。

该三阶段使用 `f5bfdcda…` 候选版；最终版补中文提示覆盖、队伍码/声部标签、过期队伍发送项处理，代存核心与结构不变。最终生产核心的主机测试通过，没有把无关 UI 更新后的完整代存重跑冒充成新射频验收。
