# 半步电台 V1.0 扩展功能简介

基于原版 ESP32-C6、128×32 OLED 和旋钮交互继续扩展，保留原有附近消息、好友、实时摩斯及学习功能，主要围绕“附近社交、宠物养成、轻量游戏和日常工具”补充体验。以下对应 2026-10-23 当前源码，不代表旧冻结固件包。

## 主要扩展

1. **消息编辑**：在设备上编辑最长 128 字符的 ASCII 消息，提供大小写、数字、符号快捷字符组和字符表情；保留快捷短语，并改善好友昵称显示。没有做中文输入法或运营商短信。
2. **附近游戏**：花旗骰、双人石头剪刀布、一藏多找寻宝、多人反应赛、数字炸弹、随机 1–10 秒盲计时。多人房间类游戏按 2–4 人设计，寻宝通过 RSSI 冷热和提示音找设备，不是精确定位。
3. **单机游戏**：竖屏俄罗斯方块和贪吃蛇，支持暂停、继续上局和最高纪录；方块有消行动画，蛇有清晰边框及三种地图。方块消行、蛇吃食物可赚宠物金币。
4. **电子宠物**：可起名，具有蛋 / 幼体 / 少年 / 成年成长阶段、照顾与训练影响的三种成年形态、四属性、需求提醒和自主动作。包含七个小游戏、金币商店、道具背包、装饰、图鉴及重新养蛋继承。
5. **宠物联机**：借鉴 Connection 的拜访与对战交互，但使用本项目自己的协议，不与正版设备互通。拜访双方获得金币和随机消耗品；对战胜、平、负都有奖励，胜者额外增加训练。
6. **工具模块**：PPT / 媒体 / 手机拍照蓝牙 HID 遥控、Wi-Fi 连接管理、Wi-Fi 扫描、BLE / RSSI 扫描和运行堆内存查看。拍照提供不同按键映射和时长，不保证所有手机兼容。
7. **在线社区**：设备联网后可自愿通过 HTTPS 上传宠物摘要和方块 / 蛇最高分，配套网页提供排行榜、宠物展示柜。默认关闭分享，可撤下自己的公开数据；不是完整存档云备份，也不是严格防作弊排行榜。
8. **系统体验**：中英文界面切换，补齐系统及游戏常用子菜单汉化；统一玩法说明含十三类宠物主题。主菜单工具提前至设置、关于之前，经典皮肤有独立工具箱图标；提供长文字滚动、三套皮肤、首页小组件及轮播。宠物自动说明完整阅读三次后不再重复弹出，仍可手动查阅。不做中文输入法，用户消息、昵称和技术标识不翻译。
9. **宠物个性化**：原房间之外增加书房 / 花园 / 太空三种金币解锁背景，可免费预览，与盆栽、星饰、地毯叠加；补充打哈欠、挠头、小跳、跳舞、摆尾和玩球等动作。

## 实现与兼容

- 开发环境：ESP-IDF 5.5.4，硬件仍为 ESP32-C6 / 4 MiB Flash；以现有按键与旋钮操作为主，不依赖新增外设。
- 附近消息和联机使用自定义 BLE 广播；Wi-Fi 用于联网与可选云分享，不是标准 Bluetooth Mesh，也不是互联网聊天。
- 当前应用 1,559,968 字节，2 MiB 应用分区剩约 524.6 KiB。为容纳功能改为 USB 单应用布局，旧三槽设备必须先完整备份再迁移，两处 NVS 地址不变，没有 OTA app 槽。
- 保留全局 NVS v7 / storage ABI 1。购买新房间后，旧固件不能识别新增房间字段，不应直接降级；详见[兼容说明](personalization.md)。
- 补充了生产逻辑的宿主回归测试、正常 UI 自动化检查及镜像 / 分区 / NVS 回读工具。本轮 COM9 已验证外观切换、轮播、房间预览、设置保持和 HTTPS 同步；不把宿主测试当作多台射频、断电或长期稳定性实测。
- 联网实测发现 TLS 计算可饿死空闲任务，已把云同步工作任务降到空闲优先级时间片运行；保留硬件加速、证书校验及看门狗。

项目方向是让原设备更适合随身社交和养成游玩，并非完整 Flipper 替代；没有新增 IR、NFC / RFID 或 Sub-GHz 硬件能力。
