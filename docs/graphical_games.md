# 图形化联机游戏

2026-10-29：UNO、快艇骰子、井字棋保留原图形操作；其他七款文字/牌类桌游已恢复并适配小屏，见[十款桌游手册](restored_tabletop.md)。只有黑白棋继续停用，协议编号保持不变。

## 入口

- 趣玩 → 多人桌游：UNO、快艇骰子、井字棋。设置 → 网络与连接开启自组网，同频道、同队伍范围，一台创建，其余加入，到齐由主机开始。
- 趣玩 → 附近竞技：石头剪刀布、寻宝雷达、多人反应赛、数字炸弹、盲猜秒数。这些使用各自附近发现机制，不需要打开多跳自组网。
- 这三款图形对局开局后自动打开游戏画面；恢复的七款从房间选择手牌、公共桌面或操作。BACK 返回房间，可查看规则、分数或结束本局；不会反复强制跳回游戏。

对局图区使用图形、数字和紧凑短标签，给牌与骰子留出空间；完整规则在中英文说明页。`TURN` 是旋转，`TAP` 是短按，`HOLD` 是长按，`WAIT` 是等对方，`SYNC` 是等待主机确认。旋转不会提交操作，等待确认或结束后短按不会重复执行。

## UNO

左边是桌面牌，中间显示最多四张自己的牌，旋转会自动翻到后续手牌；选中牌下方有白线。顶栏是当前玩家、名字、选中牌序号/自己手牌数；星号表示轮到自己。进入时牌面朝下，长按显示，再长按隐藏，重新打开游戏画面也会隐藏，避免无意泄露。

单色屏用方框、加号、实心圆和三角形代表四种花色；出同图形或同数字。牌上的 `/` 是跳过，`<>` 是反转，`+2` 是罚摸，`W` 与 `+4` 是万能牌。旋转选中自己的牌，轮到自己时短按出牌。万能牌会先出现四种图形，旋转选花色，再短按出牌；BACK 可取消花色选择。

旋转经过所有手牌后，右侧功能块依次为：

| 图标 | 操作 |
|---|---|
| `+` | 摸一张，或接受罚摸 |
| `->` | 摸牌后收手 |
| `UNO` | 剩一张时声明单牌 |
| `!` | 举报首个未声明单牌的对手 |

规则仍由主机核验；无效操作显示重试提示，不会本地假扣牌。摸牌后只能出新摸的牌或收手；罚牌不叠加，`+4` 不能在有同花色牌时打出，不含 `+4` 质疑规则。先出完牌获胜。

## 快艇骰子

五颗骰子直接显示点阵。旋转选择骰子，短按切换保留；骰子上方短横线表示保留，下方白线表示当前选择。选择右侧 `ROLL` 短按重掷未保留的骰子，每回合最多三次，右上角显示次数。

选择 `SUM` 打开计分：旋转浏览十三个项目，左侧显示中文/英文项目名，右侧 `+分数` 是当前骰子的预览；`X分数` 表示项目已用。下方十三格表示已填项目，短按把分数记到空项目并结束回合，BACK 取消。可主动记零分，已用项目不可再填。每人十三回合后总分最高者获胜；上半区达到 63 分奖励 35 分。

## 井字棋

保留完整九宫格和图形 X/O。旋转只选空格，轮到自己短按落子；横、竖或斜线三连胜，棋盘满且无连线为平局。

## 附近竞技

| 游戏 | 图形与操作 |
|---|---|
| 石头剪刀布 | 三个手势图标，旋转移动方框，短按锁定。双方锁定后展示两边手势和胜负，确认后短按下一局。顶栏保留对手昵称 |
| 寻宝雷达 | 一台旋转到藏宝，其他设备寻找；显示宝箱、雷达圈及八格信号。信号越强，中心块越大；短按锁定目标，长按开关声音。它显示信号强度，不显示方向或准确距离 |
| 多人反应赛 | 房间中四个人形槽表示玩家，角标表示准备；短按并松开准备，全部准备后五秒无新人加入则开始。等待时是空心表盘，GO 时出现明显方块与大 GO，立即按下；抢跑无效 |
| 数字炸弹 | 炸弹图标、大数字、上下界和范围条。轮到自己时旋转改数字、短按猜数；爆炸后揭示炸弹数字和出局者，短按准备下一局 |
| 盲猜秒数 | 表盘与随机 1–10 秒大目标。开始后自己默数，短按停止；途中不显示已经过去多久，避免破坏盲猜。结果展示名次与误差，旋转看其他玩家、短按下一局 |

## 验证边界

规则和状态机的宿主测试不等于实机射频验收。每次实机证据记录在忽略的 `build/`，不发布原用户存档或私人手牌截图。当前构建和实际验证范围见[验证记录](tabletop_validation.md)。
